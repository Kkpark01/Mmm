# #184 担当者名の入力上限を100文字へ変更

対象：担当者マスタ（MCM3006U）、単体テスト3006-20-01/02。
元ソース：2026-09-07に再配置した最新版src.zip。

## 修正

- 既存行・追加行の担当者名のmaxlength=40を削除。100文字まで保持し、101文字以上も勝手に切り捨てない。
- 入力欄から離れる時、Enter、日本語IME確定時、登録確認前に文字数を検証。
- 101文字以上では「入力エラー」ダイアログに「担当者は100桁以下で入力してください。」とOKボタンを表示し、登録を止める。
- サーバー側でもDB処理の前に同じ上限を検証。不正な直接送信にも同じエラーメッセージを返す。削除対象の行は長さ検証から除外。
- TantoEntityのTANTO_NK定義をlength=100へ変更。
- 長さの計算は既存のJava/JavaScriptと同じUTF-16単位。通常の日本語・英数字は1文字、サロゲートペアの文字は2として数える。

## DB列の確認

実DBへの接続・更新は未実施。Javaの@Column変更だけでは、既存DBの列幅が広がるとは限らない。反映先のMCM_MO_TANTO.TANTO_NKが日本語100文字を格納できることを確認すること。100文字未満の定義ならDB側の拡張も必要。

SQL Serverでの確認用SQL（参照のみ）：

```sql
SELECT TABLE_SCHEMA, TABLE_NAME, COLUMN_NAME, DATA_TYPE,
       CHARACTER_MAXIMUM_LENGTH, IS_NULLABLE, COLLATION_NAME
FROM INFORMATION_SCHEMA.COLUMNS
WHERE TABLE_NAME = 'MCM_MO_TANTO' AND COLUMN_NAME = 'TANTO_NK';
```

nvarchar(100)以上なら通常の日本語100文字を保持できる。varcharの場合は照合順序やバイト数も確認し、実定義に合わせて拡張する。DB型・NULL可否・依存関係が未確認のため、型を推測したALTER文は同梱していない。
