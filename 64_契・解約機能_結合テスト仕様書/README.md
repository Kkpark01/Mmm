## 実施方法

1. 「課題・要確認」の条件を確認し、「データ準備」の対象ID・実行月・環境・担当者を記録します。Q付きケースは条件と期待を確定してから実施します。
2. INT01からINT08の各業務フローを進め、INT09で権限・排他・セッション・保存先を確認します。別人の操作は独立したブラウザーのログインセッションを使用します。
3. 各ケースのI～O列に結果・担当者・実施日・不具合・再テスト結果を記入します。P列の最終判定は再テスト結果を優先して自動計算し、目次へ集計します。
4. 対象キー・変更前後のDB・出力・添付の証跡を残します。DB照合は対象キーを絞った読取で行います。

「保留」集計は未実施も含む残件です。合格率はOK件数／対象外を除く実テスト件数。実行欄はすべて未記入です。
