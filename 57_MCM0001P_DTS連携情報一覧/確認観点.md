# MCM0001P 確認観点・実装前の差異

根拠：Mcm0001pExcel/Constant.vb、Mcm0020uScreen/Designer.vb、CPDataGridView.GetListData、CPExcelManager.OutputCSVFormat/OutputColumnList、CPColorConstant、共通仕様1章・4章。

| 観点 | VBの期待動作／Webの対応 |
|---|---|
| 起動 | MCM0020U「Excel出力」。Webの未実装案内を帳票へ接続する |
| 対象 | DTSログ／現在状態の表示済み全行。条件を書き換えても再検索しない |
| 列 | ログ出力日、納入先コード、納入先名、サポートID、プラント名、内容。内部ID・リンク重複列は出さない |
| 順序 | 一覧の行順を維持。Webには画面内ソート機能がない |
| 書式 | 日付yyyy/mm/dd、他5列は文字列。先頭ゼロ・長いID・改行を保持、数式として解釈しない |
| 装飾 | VBのColorIndex20（#CCFFFF）の見出し、使用範囲の罫線。独自の青・太字を撤去 |
| 権限 | ExcelボタンはAuthorityIsThrough=True。参照権限でも出力、未ログインは既存SecurityConfigで拒否。帳票直URLにも起動元MCM0020Uの共通権限検査を適用 |
| 0件 | MSG_0002の案内。VBは案内後も出力へ進むが、Webは空帳票の取得を止める |
| 状態 | 既存のタブ別検索スナップショット（上限5）を共有し、タブ混在・再出力・子画面から戻る動作を確認 |
| エラー | 未検索・期限切れ・生成失敗を共通通知で案内。生成失敗後も検索結果・入力途中の条件・モード・選択行・スクロール位置を維持。日付前後エラーの文言を共通通知のVB定義に一致させる |
| HTTP | 日本語xlsx名、正しいMIME、キャッシュ禁止。サーバーへのファイル保存やOffice起動は不要 |
| 境界 | null、0行、複数行、6000行、期限切れ、別セッション、同一結果の反復出力 |
| 影響 | 検索SQLと入力検査・既存#344の戻り状態保持を維持。56の対象と重複しない |

帳票はテンプレートを使わないVBの汎用Excel出力。列幅はWebの既存自動調整を維持し、専用画面・PDF・別の待機画面は追加しない。MCM0020Uは帳票操作を変更するため共通レイアウトと共通通知へ接続するが、リンク権限等の別機能の全面改修は行わない。
