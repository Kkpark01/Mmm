# MCM0021U 第2段階：検索一覧の連動・検索結果保持

第1段階のレイアウトと#191の空値ガードを含む累積修正版。最新版src.zipを基に作成。mcm-web本体には未反映。

## 今回の修正

- プラントを選択すると、そのプラントIDの機器構成だけを表示する。
- 機器構成を選択すると、機器構成IDとブランド構成IDの両方に一致する明細だけを表示する。VBのXSDリレーションに合わせている。
- プラント変更時は子一覧の先頭を選択し、子がない場合は機器構成・明細・選択IDをクリアする。行番号も表示中の行で振り直す。
- BigDecimalの20/20.0などの表記差を吸収。ブラウザーのID照合は文字列で行い、大きなIDをNumberへ変換しない。
- 元/先設定後は検索条件、検索結果3一覧、プラントと機器構成/ブランドの選択を保持。再検索せず保存した検索結果を復元する。
- 元/先設定後の戻り先は /mcm0021u?resume=true。再読込も同じ検索状態を復元。通常の /mcm0021u からの入場や別画面からのplantId連携時は検索状態をリセットする。
- 検索結果ごとに識別値を発行し、元/先設定時に現在の検索結果と送信IDを照合する。検索前、0件、結果にないID、古い検索画面からの設定を拒否する。
- 再検索開始時に以前の対象を無効化。検索条件が空・検索0件・検索失敗で古い結果を設定できない。
- plantIdの未送信・空・0・数値以外でも「付替え対象が検索されていません。」を表示し、設定済みの元情報を変更しない。
- 元に設定するプラントに検索結果上の機器構成がなければ、元取得処理の前に「機器構成情報が存在しません。」で中断。構成が未登録のプラントも付替え先には設定できる。
- 付替え先の納入先名などは送信hiddenではなく検索結果DTOから取得する。
- 元/先プラントIDを画面のformにも反映し、表示とhidden値を合わせる。
