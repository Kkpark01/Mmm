# 129：メーカー契約機器リストの取得・加工改善（検証版）

128の重複確認改善を引き継ぎ、未契約一覧の検索、備考処理、製番引当を改善した検証版です。129単独で使用できます。122・128への上書きは不要です。

## 変更内容

1. 全件取得で使用する「32機器一覧『未契約』」の検索を、EXTRACT6ビューの絞り込みと後続の結合に分割しました。検証DBで同じSQL案は1分49秒・253,182行で終了したと報告されています。元SQLとの結果・処理時間比較は未実施です。
2. 128と同様に重複を後方から一度ずつ判定し、同じIDの最後の行を残します。文字列以外を含む場合は従来の判定を使用します。
3. 備考編集中の表示更新を毎行から200件ごとへ変更しました。備考の内容や条件は変更していません。
4. 自動計算のとき、製番4列の式を設定する間の再計算をまとめ、値へ変換する前に対象範囲を計算します。元が手動計算のときは従来の挙動を維持します。エラー時にも元の計算設定を戻します。

未契約以外のDB検索、取得データの列、検索条件、出力順、ファイル名、接続設定は変更していません。検索用の一時テーブルは接続中だけ利用します。

## 使い方

1. `配布用/MCM業務マクロ/08_メーカ契約機器リスト作成` をフォルダごと検証PCにコピーし、Excel、Mcm移行部品、原紙を一緒に保持します。
2. McmMacroSettings.iniの検証DB・認証方式を確認します。一時テーブルを使用できる権限とtempdbの空きが必要です。
3. 操作シート②「データリスト作成」を押し、完了までの時間とExcel下部の表示を確認します。
4. 同じ検証DB・同じ時点・同じ条件の基準結果と、件数・重複で残った行・備考・製番開始／終了・HW／SW製番・日付・金額・帳票を比較します。データが更新されている間の比較には注意してください。

## 確認内容

- 未契約の検証SQLは、元SQLとの構文上の絞り込み・4結合・109列・並び順を確認。実DBでのSQL単体は1分49秒・253,182行。SQL内蔵復元とADOコマンド作成はExcel上の模擬環境で成功。
- 重複判定・行削除後の内容と並び順を模擬データで元版と比較し一致。架空の重複なし253,182件では約3.57秒で全件判定。
- 備考3列は模擬6,000行で128と一致（旧約0.70秒、新約0.04秒）。
- 製番4列は模擬6,000行で修正前後が一致。自動計算では約0.61秒から約0.40秒、手動計算も一致。故障を注入した試験でエラー伝達と計算設定の復元を確認。
- 128との差は内蔵SQLシートとGet_MCM_DATAモジュールのみ。これら以外のExcel部品や同梱設定・原紙は維持。Excelはテスト用コピーで開いて検証。

## 未確認事項

- 元の未契約SQLと同じ検証DB・同じデータで、全件の値・重複・並び順が一致すること。ビューの読み込みを段階化するため、他者が同時に更新する場合は取得時点に差が生じる可能性があります。
- Excelから検証DBへのADO接続・複数文・一時テーブルの実行、253,182件のExcelへの展開、全処理時間、作成帳票。
- 契約中・解約・サポートID指定用のSQL性能と、実機での製番・金額。改善効果は実データと利用環境によって異なります。

検証用のため、実環境で内容と速度を確認してから業務利用してください。管理者用に修正VBAと内蔵SQLの原本を保存しています。
