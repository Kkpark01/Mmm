提供ファイルは内容を変更せずに配置。WorkbookFactoryで読み込み、元形式のxlsで出力します。ダウンロード名もxls、Content-Typeも `application/vnd.ms-excel` に揃えました。項目位置はテンプレートと既存Java定数で対応しています。

VBのSetTemplateSheetsにならい、すべてのシートを記入前の原紙から複製。以前のJavaは記入後の1枚目を複製するため、次の明細件数が少ない場合に余分な明細が残る構造でした。シート名の禁止文字・同じ時間帯名にも対応。出力ヘッダーが0件の場合は空の原紙を正常出力しません。
