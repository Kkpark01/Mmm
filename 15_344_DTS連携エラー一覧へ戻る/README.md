## 保持範囲

検索結果はセッションごとに最新5回分を保持します。セッション切れや6回以上の新しい検索で対象が失われた場合は、再検索を促すメッセージを表示し、自動検索はしません。

ブラウザのsessionStorageと同一サイトの遷移元情報を使ってタブ単位で判定します。利用制限等で遷移元を確認できない場合は、仕様どおりメニュー起動扱いになります。復元する一覧は遷移前の内容なので、付替え後のDB状態を確認したい場合は利用者が改めて検索してください。
