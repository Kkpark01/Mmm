## 修正

MCM1003Uの検索SQLに限り、基表が「契約3・見積契約時間1」の組み合わせの場合に補正します。

- 表示状態と検索条件判定を、ともに「見積」にする。
- 見積破棄・契約作成のリンク値を設定し、契約破棄リンクを無効にする。
- 見積自体も破棄された行、契約中・解約等の行は従来のビュー値を使用する。
- 既存の契約番号・契約履歴IDや承認表示、利用者の権限制御を維持する。

「見積破棄」リンクの表示は見積へ戻った場合の正常な操作です。それ自体を不具合の判断基準にしないでください。検索条件が「契約」のみなら、破棄後に一覧から消えるのも正常です。「見積」を含めて検索してください。

共通ビューは他画面も参照するため変更しません。Serviceの更新処理・支払判定・トランザクションも変更しません。
