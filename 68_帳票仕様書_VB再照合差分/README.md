- [確認範囲と残る確認.md](確認範囲と残る確認.md)：対象10帳票の確認観点、Webへの移行差異、実環境で残る確認。

今回は依頼どおり**差分の記録のみ**です。65・66・67のMDとExcel、最新src、VB資料は変更していません。Excel／MDへの反映は次の作業です。

## 主な確認結果

1. 結合MDが一覧系帳票の参照権限を一律に許可していますが、VBの依頼一覧出力（1002P）は参照権限で非活性です。単体1002P-15の期待結果はこの点で正しいです。
2. 単体2001Pの5・6番目のシート順が、VB定数の役割順と逆です。
3. 支払帳票の製番に付く「*」は、取引先契約の解約日ではなく、関連ユーザー契約の解約日で判定します。
4. 更新依頼書の解約欄にも全項目の値が入るという期待は誤りです。解約日未入力で更新する場合、解約日欄は空欄です。

確認は静的な資料・コード照合です。実DB、ブラウザー操作、Office表示・印刷、現行VB帳票の実出力は未実施。他6帳票の正式VB原紙がそろっていないため、原紙全体の完全一致は判定していません。
