# INT03 修正反映Excel

2026-10-17。[97の了承済み本文](../97_INT03_実施範囲整理案/INT03_パック店舗直_実施範囲整理案.md)を、94のINT02・INT05修正版Excelへ反映した統合版。

ファイル：`MCM契・解約機能_結合テスト仕様書(261009版)_INT02・INT03・INT05修正版.xlsx`

## 反映内容・使用方法

このExcelをINT02・INT03・INT05反映済み版として使用する。原本や94へ上書きする必要はない。

- INT03全19項番のC～G列・P列、10～28行の計114セルへ、8項目構造の本文をセル内の平文へ変換して反映。
- 08・16は別PCの実施者A・Bによる3手順の画面確認。追加DB確認は省略。
- 15は店舗直のソート個別要件が確認できないため対象外。共通仕様9・9.1に基づく理由を前提・備考に記載。
- ON／OFFを「チェックを入れる／外す」、受領Web等を「Web版」に統一。
- 既存の対象外登録方式に合わせ、15のH24を「対象外」に設定。最終判定・INT03集計・目次集計は既存数式を維持して計算結果を更新。INT03は実施予定18件・対象外1件。実施予定18件は「未実施」のまま。
- 操作手順とメッセージの末尾を読めるよう、INT03のE列幅を52.5から125、G列幅を25.25から80へ調整。行高・フォント・他の列幅は維持。
