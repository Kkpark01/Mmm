# INT05 全19項目の簡潔化修正案

2026-10-16。[修正案本文](INT05_製番契約解約_簡潔化修正案.md)。提示済みのINT05-01を含め、全19件を02～04と同じ項目構造で整理した。Excelへの反映前の本文案であり、実施実績は更新していない。

## 対象・変更理由

基準は `92_INT02_修正反映Excel` のExcelにある `INT05_製番契約解約`。84の全文MDは補助資料として参照し、置換していない。

各項目の準備・操作・確認を主目的に絞り、繰り返されていた別プラント・全期間・全機器・監査情報の一括DB比較を省いた。支払帳票は13の代表確認へ集約した。01は利用者へ提示した本文を収録し、同じ書き方で02～19を作成した。

| 項番 | 整理した範囲 |
|---|---|
| 01～06・12 | 画面参照・検索を中心にし、DB確認は実施不要と記載。05の2プラントは切替確認に必要なので残した。 |
| 07・09 | 見積・ブランドまたは機器を各1件とし、作成・登録・元見積との関連を確認。必要な入力と画面操作は残した。 |
| 08・10・11 | 破棄の可否と対象契約・元見積のDB状態に絞った。11の他入口画面での再試行と帳票前後比較は省いた。 |
| 13 | 製番登録→別担当者の確認→契約再表示→支払出力を代表1件で残した。 |
| 14～16・18 | 本人除外、未・再の確認、キャンセル、本人依頼だけの場合を個別に確認。DBは対象製番の確認情報・依頼情報に限定。 |
| 17 | 独立した2セッション・同じ製番1件で、先行者の確認情報が保たれることを確認。通知の未確定事項Q06は維持。 |
| 19 | 最大期間が有効な通常データで検索を確認。期間の金額を区別し、最大期間の情報を表示することと、済の非表示を残した。DBは準備時の照合のみ。 |

## 減らした観点と残る制約

- 15は「未・再の一括確認」に題名を変更し、既に確認済みの別製番の保存情報との保護比較を省いた。済の非表示は19で確認する。
- 16はキャンセルによる製番情報の不変に絞り、支払抽出の前後比較を省いた。
- 18は本人依頼だけに絞った。通常画面に表示されない確認済み行を内部データとして渡す試験は、技術側の確認候補へ分離した。
- 19の「最大期間が無効・古い期間だけ有効」の条件は、技術側の確認候補へ分離した。技術側で確認済みとしたわけではない。
- 17の後行者の正式な拒否通知はQ06で未確定。DBの保護が成立したことだけで通知も含めて合格にしない。

期待メッセージはVB定義を基準とした。受領Webとの差異は、06の0件文言、08・10の追加完了通知、09の登録完了文言、11の拒否文言、17の競合時通知、18の確認順に記載した。保存結果と通知差異を分けて記録する。
