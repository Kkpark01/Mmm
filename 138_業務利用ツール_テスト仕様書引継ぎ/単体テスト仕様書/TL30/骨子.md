# TL30（申請前check.vbs） 骨子

旧版を根拠とする移行試験仕様を6件で作成。移行版の実装は未作成で、試験実施可能とは判定しない。

| 項番 | 確認内容 | 根拠・準備 |
|---|---|---|
| 001 | 指定見積の全明細、金額・期間・開始日順 | 旧SQLと表示生成。Aと期待表 |
| 002 | 再試行の初期値と結果入替 | EstNo再利用とReadingTextクリア。区別できるA・B |
| 003 | 正常0件と旧表示消去 | 見出しPROMPTとFEEDBACK OFF。Aの後にZ |
| 005 | 入力取消・空欄・結果取消で終了 | 結果取消は原本。入力時は移行要求 |
| 006 | 現行比較 | 同時点の両DBと実行可能な両版 |
| 007 | 取得失敗と旧結果誤表示防止 | 移行要求。独立した代替取得処理 |

004は帳票出力機能がないため作らない。英字・複数明細・同一開始日は001へまとめ、存在するデータだけで判定する。NULL金額・桁上限超の表記は根拠取得まで適用保留。取得失敗を再現するために共有DBを停止しない。

全文の完成と実装・試験完了を区別する。[確認観点対応](../TL30-32_確認観点対応.md)で採用範囲と実施前の条件を確認する。
