# TL05（終息リスト作成ver3.7.xlsm） 用語表

抜き出し元：改修版 `改修版_業務利用ツール\マクロ実行フォルダ\配布用\MCM業務マクロ\05_終息リスト作成OK\終息リスト作成ver3.7.xlsm`（読み取り専用。2026/11/02）。VBA（Get_MCM_DATA、■Payout、Output_List、Data_Delete、Machine_Class_Create、McmEndData、McmAdoClient、McmFiles）、内蔵SQL queries/（support、external_01〜06）、シートの文字、ボタンの図形を照合した。元のツールとの照合は、取得の部分（Get_MCM）に限る（以前の調査 `マクロ調査\vba\10_終息リスト作成ver3.6…`。配布版は ver3.7 のため、版が違う）。

## 1. シートとファイル

| 表示名 | 用途 |
|---|---|
| 操作シート | ボタン、支払データ抽出対象の年月（N4、P4）、サポートID指定（M12） |
| 取込データ | 取得した機器の一覧。「データリスト作成」などで作り直される（約30万行まで）。A〜DI列 |
| 店舗リスト | サポートID別の担当店舗（A列＝サポートID、B列＝店舗）。新しいサポートIDは、取得のときにA列へ追記され、B列は空になる |
| 機器分類表、個別機器分類表 | 機器管理IDごとの機器分類の引当て元 |
| 製番データ、取引先データ | 取得のたびに作り直されるシート（製番、個体の取引先） |
| temp | サポートID付替えの一時シート |
| サポートID指定SQL | 非表示。元のツールのSQL（Oracle）。改修版では実行しない |
| システムコード変換表.xlsx | サポートID付替えの変換表。設定ファイル Reference_01 の場所を開く（今はツールのフォルダーの写し。元のツールは共有フォルダー） |
| _【テンプレート】店舗別　『機器一覧』.xlsx | 「終息リスト作成」の出力の原紙。ツールと同じフォルダーに必要 |
| 【テンプレート】支払一覧.xlsx | 「支払いデータ抽出」の出力の原紙。ツールと同じフォルダーに必要。シートは「支払一覧」「取込リスト」「製番リスト」「取引先契約期間データ」であること。改修版05のフォルダーのファイルは別ツール（02_支払いデータ取得）用でこのシートがなかったため、終息リスト作成用に入れ替えた（2026/11/02。00_進捗.md 2.1章） |

## 4. 取得（内蔵SQL）

| 取得 | ファイル名（内部の名前） | 内蔵SQL | 条件 |
|---|---|---|---|
| 全件 | 32機器一覧「未契約」、35機器一覧「解約（途中解約）」、31機器一覧「契約」（各109列） | external_03、external_01、external_02 | 3種類を、この順に「取込データ」へ連結 |
| 契約中 | 31機器一覧「契約」 | external_02 | － |
| サポートID指定 | サポートID指定終息リスト（109列） | support.sql | EX6.SUPPORT_ID＝M12（7桁）、先頭2桁が99でない、状態・撤去日・備考の条件（★不要、★【撤去済み】、★【重複ﾃﾞｰﾀ】を除く） |
| 付随データ | 36契約製番（6列）、37取引先契約期間情報（8列）、38個体取引先（2列） | external_04、external_05、external_06 | 全件。取得のたびに、非表示シートへ保存する |

検証DBで実行（2026/11/02、見るだけ）：support.sql（M12＝1700140）30行、external_04 1,760行、external_05 4,622行、external_06 161,707行、external_01（解約）47,759行（106秒）、external_02（契約）61,592行（167秒）、external_03（未契約）253,914行（208秒）。いずれもエラーなし。3種類の合計は 363,265行で、重複する機器管理IDを除くと「取込データ」に入る行数は、これより少なくなる（保存済みのブックの取込データは 299,056行）。「データリスト作成」の取得だけで約8分かかる見込み。

## 6. 出力ファイル

- 「終息リスト作成」：「店舗別　『機器一覧』_」＋実行日時（yyyymmdd_hhnnss）＋「.xlsx」。保存先はツールと同じフォルダー（McmOutput.PathFor）。
- 「支払いデータ抽出」：「【BCP対策】支払一覧」＋実行日時（yyyymmdd_hhmm）＋「.xlsx」。保存先は同じ。

## 7. 元のツールとの違い

| 項目 | 元のツール | 改修版 | 扱い |

| 取得前の出力 | 保存済みの「取込データ」から、すぐ出力できる | 同じ版で取得を終えていないと止まる | 【作成者回答 B（2026/11/02）：元のツールに合わせて直す】。VBAの修正は作成者が行う（00_進捗.md 2.1章）。直したあとのブックで、TL05-004・005 を実施する |
| システムコード変換表の読み先 | 共有フォルダー | ツールのフォルダーの写し（設定ファイル Reference_01） | 本番は共有フォルダーを読む。Reference_01 の行を消す作業を 00_進捗.md 2.2章に記録した |
