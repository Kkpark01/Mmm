## 4. 取得の条件（内蔵SQL）

| ボタン | ヘッダ（18列） | 明細（17列） | 条件 |
|---|---|---|---|
| 新規契約 | T14_00_default_01 | T14_00_default_02 | 契約番号＝C3。有効な期間（YUKO_FLG＝0）のうち最も新しい期間 |
| 解約依頼 | T14_01_xx_01 | T14_01_xx_02 | 契約番号＝C10（、D10、E10）。解約日がその期間の開始日より後で、終了日以前の、有効な期間のうち最も新しい期間。xx は D10・E10 の空欄の組み合わせ（00、01、10、11） |
| 契約更新 | 上の2つを続けて行う | | |

- ヘッダは、支払明細の月ごとに1行を返す。マクロが支払月をまとめて「1月、4月」の形にし、支払回数が12以外なら「年n回　月」、12なら「年12回」にする。時間帯に「H」を付ける。担当者名に「様」がなければ「 様」を付ける。
- 明細は、個体ごとに1行を返す。製番・シリアル番号・同じ型式の数量をまとめ、機器構成ごとの見出しとページ分け（1ページ目20件、2ページ目から50件）をする（元のツールと同じ処理）。
- 検証DBで実行（2026/11/02、見るだけ）：契約番号「2104-007」でヘッダ12行・明細3行。解約の条件（契約番号1件、解約日を期間の中に指定）でヘッダ4行・明細2行。エラーなし、列の数は18・17。

## 5. 出力ファイル

- ファイル名：サポートID（7桁）＋「_」＋納入先名＋「_契約手続依頼書_」（解約は「_解約手続依頼書_」、更新は「_契約更新手続依頼書_」）＋契約番号（「/」は「,」に置き換え）＋「_date」＋日時（YYYYMMDD_hhmmss）＋「.xls」。「株式会社」「有限会社」は名前から消す。
- 保存先：ツールのブックと同じフォルダー（McmOutput.PathFor。元のツールも同じフォルダー）。形式は Excel 97-2003（.xls）。

## 8. 依頼書のセル（edit_headerform、edit_form）

テンプレートは .xls（Excel 97-2003）のため、ラベルの文字はこの調査では読めていない。【要確認】ラベルの文字（実施のときに記録する）。書き込み先のセルは、VBA から確認した。

1ページ目のシート「契約手続依頼書①」（明細が多いときは「契約手続依頼書【2】」などが増える）：

|---|---|---|---|
| F1 | 「□新規契約」が「■新規契約」になる | 「□解約」が「■解約」になる | 「□更新」が「■更新」になる |
| P1 | 「作成日：」＋実行日（YYYY/MM/DD） | 同左 | 同左 |
| P2 | 「( 1 / 全ページ数 )」 | 同左 | 同左 |
| D3 | 取引先名 | 同左 | 同左 |
| D4 | 取引先担当者（「様」がなければ「 様」を付ける） | 同左 | 同左 |
| D6 | 納入先名＋半角スペース＋工場名 | 同左 | 同左 |
| D7 | 〒郵便番号＋半角スペース＋住所 | 同左 | 同左 |
| D8、D9 | 納入先の電話番号、部署 | 同左 | 同左 |
| D10 | サポートID（7桁） | 同左 | 同左 |
| I9 | 納入先担当者（「様」がなければ「 様」を付ける） | 同左 | 同左 |
