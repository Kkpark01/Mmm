# TL07（点検リスト作成） 単体テスト仕様書・本文案

構成：主要な移行機能5ケース（001・002・004・005・006）。既存仕様書の粒度に合わせ、変更のない入力補助等は補助確認として骨子へ記載する。

対象：131の09「点検リスト作成ver1.53.xlsm」。通常の点検対象・解約機器を新MCMから取得し、ブック内へ表示する。②の出力はNotes取込用xlsの作成までであり、Notesへの登録は行わない。会社編集版との照合と実機試験は未実施。

凡例：
- 実施者：Excelで操作し、表示・ファイルを確認する人。
- 準備担当者：検証DBの既存データから対象を選び、試験データ表と試験専用コピーを渡す人。DBへ新規登録しない。
- 試験データ表：取得元と加工条件を確認して、実施前に期待値を記入する表。実際の試験結果から逆算しない。空欄や対象データ不足は「準備未完」とする。
- 各ケースは独立した試験用コピーで実施する。「操作シート」にある表示名でボタンとチェックボックスを特定する。
- メッセージIDはすべて「－」。実施区分は通常／要確認／開発者テスト／実施不可／除外候補。
- DBは参照のみ。DB確認不要は更新結果の確認についてであり、期待値の準備にDBを参照することは含まない。
- [用語表](用語表.md)にセル・処理の根拠、[骨子](骨子.md)に確認範囲と追加候補を記載する。

項番の扱い：003・008・009は補助確認へ移し、独立した本文ケースを省く（骨子参照）。007は共通エラー試験の代表範囲を確認中のため本文なし。004は出力前の列構成・操作順が未確定のため、本文案を残して実施を保留する。

## TL07-001

### 項番
TL07-001

### テスト項目
TL07（点検リスト作成）：月を1つ選んで①データ取得を押すと、その月の点検対象が取得・加工され、機器情報が取込データに表示されること。

### 前提条件
```
実施区分＝通常（既存データ確保後）。

【この試験で確認すること】
初回契約開始日を空欄にして月を指定し、その月の点検対象と加工後の機器情報を確認する。

【実施する人】
・実施者（Excelを操作する人）。
・準備担当者（既存の点検対象と加工後の期待値を用意する人）。

【実施者に必要なもの】
・マクロを有効にできるExcelと、09_点検リスト作成のフォルダー一式の試験用コピー。
・接続ドライバー・認証が準備され、Mcm移行部品の設定で検証DBに接続することを確認済み。
・Reference_01のシステムコード変換表にアクセスできること。試験用コピーを使い、共有原本は変更しない。

【準備担当者が用意するデータ】
通常取得SQLに該当する既存機器を1～3件選び、その契約点検月の月をMとする。両契約の契約状態・現在有効な期間・点検回数・機器分類を確認する。取得後の解約日による除外で消える機器は選ばない。
修正リスト・構成名リスト・サポートID変換表も確認し、適用後の値を書く。少なくとも1件は構成名リストに修正名が登録済みの機器を使う。

試験データ表（機器ごとに記入）：
| 対象月M／実施日／DBサーバーの日付 | |
| 機器管理ID／ユーザ契約ID | |
| 点検予定年月／契約点検月（年補正後） | |
| サポートID／納入先コード／契約No. | |
| ユーザー名／システム名 | |
| 加工後の機器構成名／品名／型式／数量 | |
| 元の契約No.が空欄の機器（ある場合） | |
契約No.空欄は「確認中」、構成名はブランド詳細名と修正構成名を「 / 」で連結した値を期待値にする。

【開始時の状態】
Excelを起動していなくてよい。変換表は閉じておく。試験中にDBやマスタの値を変更しない。
```

### 操作内容
```
1. 試験用の「点検リスト作成ver1.53.xlsm」を開き、マクロを有効にして「操作シート」を選ぶ。
2. B18（初回契約開始日）をDeleteキーで空にする。
3. 「選択解除」（B10付近）を押し、試験データ表のM月のチェックボックスだけを選択する。
4. 「当月データを作成対象にする」（I2付近）を選択済みにする。
5. 「①データ取得」（I3付近）を押す。完了通知の全文を控え、「OK」を押す。追加の修正案内があれば、そのシートの追加行も控える。
6. 「取込データ」を選ぶ。A列を選択してCtrl＋Fを押し、機器管理IDを完全一致で検索する。対象行のG・H・J・K・L・N・P・Y・AA～ACを試験データ表と照合する。
7. H列（契約点検月）の月が選んだM月だけであることを確認する。取込データと完了通知をエビデンスとして記録する。
8. 試験用ツールを保存せずに閉じる。

【入力値】
B18＝空欄。対象月＝M月のみ。I2＝選択。
```

### 期待結果
```
【画面確認】
・「データ抽出が完了しました。」が表示される。
・選んだ機器管理IDがA列に存在し、G＝点検予定年月、H＝契約点検月、J＝サポートID、K＝納入先コード、L＝契約No.が準備値と一致する。
・N＝ユーザー名、P＝システム名、Y＝機器構成名、AA＝品名、AB＝型式、AC＝数量が加工後の準備値と一致する。
・H列にはM月以外の月が含まれない。元の契約No.が空欄の機器を選んだ場合、L列は「確認中」。
・追加案内が表示された場合は、「機器修正リスト」「機器構成名リスト」のうち案内されたシートに対象の機器管理IDまたは構成IDの追加行がある。案内が出たことだけで取得失敗とは判定しない。未修正行の出力可否は別途確認する。

【DB確認】
実施不要（取得・ブック内加工のみで、DB更新なし）。
```

### 期待メッセージ
```
表示タイミング＝手順5の通常取得・加工完了時。
表示形式＝Excelメッセージボックス。通常は情報、修正案内付きは警告。
メッセージID＝－。
表示文言＝「データ抽出が完了しました。」
型式の新規修正対象がある場合、空行を挟んで次を追記：
品名／型式修正が必要です。
『機器修正リスト』シートを確認してください。
構成IDの未登録対象がある場合、空行を挟んで次を追記：
新規機器構成IDが追加されてます。
『機器構成名リスト』シートを確認してください。
両方ある場合は上記の順に追記。
作業者操作＝全文を控えて「OK」を押し、案内されたリストの追加行を記録する。
```

### 備考
通常取得直後には照合用M列が追加される。このケースの列位置はその状態を前提とする。再適用ボタンの試験は含めない。全列・全行の値照合や全警告分岐を確認済みとは扱わない。

## TL07-002

### 項番
TL07-002

### テスト項目
TL07（点検リスト作成）：初回契約開始日の指定日を含めて抽出し、指定日より前の契約を除外し、対象なしでは0件通知となること。

### 前提条件
```
実施区分＝通常（境界データ確保後）。

【この試験で確認すること】
B18の条件が「初回契約日≧指定日」で働くことと、全対象より後の日付で0件になること。

【実施する人】
・実施者（3条件で取得する人）。
・準備担当者（既存の境界契約と日付を確認する人）。

【実施者に必要なもの】
・検証DB接続・認証・ドライバーを準備した09フォルダー一式と、マクロを実行できるExcel。
・Reference_01で参照する試験用システムコード変換表。
・各条件を別々に試すため、同じ初期ブックの試験用コピー3つ。

【準備担当者が用意するデータ】
同じ対象月Mの通常取得条件と加工後の条件を満たす機器A・Bを既存契約から選ぶ。
Aのユーザ契約初回契約日をD、BはDの翌日以降とする。両方とも解約除外されないものを選ぶ。
Zは、選択月Mの通常取得候補全体の最大の初回契約日より後で、日付として入力できる値とする。実施前に取得元を確認し、単にシステム日付より未来というだけでは選ばない。

試験データ表：
| 対象月M／日付D／Dの翌日／0件用の日付Z | |
| 機器Aの管理ID／ユーザ契約ID／初回契約日D | |
| 機器Bの管理ID／ユーザ契約ID／初回契約日 | |
| Zが全候補の初回契約日より後である確認根拠 | |

【開始時の状態】
Excelを起動していなくてよい。3つの試験用コピーは、同じDB時点・同じ修正リストから開始する。
```

### 操作内容
```
1. 1つ目の試験用ブックを開き、「操作シート」を選ぶ。「選択解除」を押してM月だけ選択し、I2の「当月データを作成対象にする」を選択する。B18へDを年月日で入力する。
2. 「①データ取得」を押し、完了通知を記録して「OK」を押す。「取込データ」A列で機器A・Bを完全一致で検索し、両方が存在することを確認する。保存せずに閉じる。
3. 2つ目の試験用ブックを開く。手順1と同じ月・I2を設定し、B18だけDの翌日にする。①で取得し、完了通知の「OK」を押す。
4. 「取込データ」A列で機器A・Bを検索する。Aは存在せず、Bは存在することを確認する。保存せずに閉じる。
5. 3つ目の試験用ブックを開く。月・I2を同じにし、B18へZを入力する。①で取得し、通知全文を控えて「OK」を押す。
6. 「取込データ」に見出し以外のデータ行がないことを確認し、保存せずに閉じる。

【入力値】
対象月＝M月のみ、I2＝選択を3回とも共通とする。B18＝D／Dの翌日／Z。
```

### 期待結果
```
【画面確認】
・B18＝Dでは機器A・Bが存在する。
・B18＝Dの翌日ではAが存在せず、Bが存在する。
・B18＝Zでは「点検対象データがありません。」と処理終了の通知が表示され、取込データに明細がない。「データ抽出が完了しました。」は表示されない。

【DB確認】
実施不要（3回とも参照のみ）。初回契約日は準備時に取得元で確認する。
```

### 期待メッセージ
```
表示タイミング＝手順2・3の加工完了時と、手順5の0件判定時。
表示形式＝Excelメッセージボックス。
メッセージID＝－。
手順2・3の表示文言＝「データ抽出が完了しました。」。修正案内がある場合は、空行を挟み「品名／型式修正が必要です。」「『機器修正リスト』シートを確認してください。」、または「新規機器構成IDが追加されてます。」「『機器構成名リスト』シートを確認してください。」を追記する。
手順5の表示文言＝
点検対象データがありません。

処理を終了します。
作業者操作＝通知を記録し、それぞれ「OK」を押す。
```

### 備考
①の前にB18を空欄にする手順は入れない。意図した指定条件を消さないため。DやZは試験用に入力する日付であり、DBの契約日を変更するものではない。

## TL07-005

### 項番
TL07-005

TL07（点検リスト作成）：解約日を指定すると、指定日以降の解約機器が解約データへ表示され、現在の点検対象機器を含まないこと。

### 前提条件
```
実施区分＝要確認（139で修正を用意済み。会社編集版への反映確認と試験データの準備ができるまでは実施保留）。

【この試験で確認すること】
ユーザ契約または取引先契約の解約日による下限条件と、現在の点検対象の除外、解約データの加工結果。

【実施する人】
・実施者（解約機器出力を操作する人）。
```

## TL07-006

### 項番
TL07-006

### テスト項目
TL07（点検リスト作成）：現行版と改修版で同じ元データ・対象月・日付条件を使い、取得件数と機器の加工結果を比較すること。

### 前提条件
```
実施区分＝要確認。データ時点を揃えられなければ実施不可。

【この試験で確認すること】
移行前後の通常取得について、全データ行数と選んだ機器の指定項目を比較する。

【実施する人】
・実施者（両版を別々に実行する人）。
・準備担当者（元データの時点、変換表・修正リスト、対象条件を揃える人）。

【実施者に必要なもの】
・実行可能な現行版と改修版の試験用フォルダー。両版の接続・認証とマクロ実行環境。
・同じ内容のシステムコード変換表、機器修正リスト、構成名リスト。

【準備担当者が用意するデータ】
両DBの元データ時点が一致することを確認する。月Mの通常取得に残る既存機器を1～3件選ぶ。両実行でPC・DBの日付を跨がない。

試験データ表：
| 両版のファイル名・接続先識別名／元データ時点の一致根拠 | |
| 対象月M／初回契約開始日（空欄または実在値）／I2の状態 | |
| 機器管理ID一覧／変換表と修正リストの版 | |

【開始時の状態】
Excelを起動していなくてよい。両版を別フォルダーに置き、取得後の同じ段階で比較する。
```

### 操作内容
```
1. 現行版を開き「操作シート」で試験データ表の月・B18・I2を設定し、「①データ取得」を押す。通知全文を記録して「OK」を押す。
2. 「取込データ」の行数を控える。選んだ機器管理IDをA列で検索し、点検予定年月・契約点検月・サポートID・契約No.・ユーザー名・機器構成名・品名・型式・数量を、項目名とともに比較用ブックの「現行」へ値で転記する。保存せずにツールを閉じる。
3. 改修版を開き、同じ条件で①を実行する。同じ行数と項目を比較用ブックの「改修」へ値で転記する。
4. 全行数と機器管理IDごとの各値を比較する。列番号だけで対応付けず、見出し・追加照合列の有無を確認する。日付は年月日、識別値は先頭0を含む文字、数量は数値で照合する。
5. 差があればID・項目名・両値を記録する。比較結果を保存し、ツールは保存せずに閉じる。

【入力値】
両版の月M・B18・I2を同じにする。
```

### 期待結果
```
【画面・比較用ブック確認】
・通常取得の全行数が一致し、選んだ機器管理IDと指定項目の値が一致する。
・差が出た場合は、元データ時点・マスタ版・実行日・加工処理を確認する。説明が確定するまで一致または合格と扱わない。

【DB確認】
更新確認は不要。両DBの元データ時点が一致するかは準備時に確認する。
```

### 期待メッセージ
```
表示タイミング＝両版の①の完了時。
表示形式＝Excelメッセージボックス。
メッセージID＝－。
改修版の表示文言＝「データ抽出が完了しました。」。新規修正対象がある場合は「品名／型式修正が必要です。」「『機器修正リスト』シートを確認してください。」、未登録構成IDがある場合は「新規機器構成IDが追加されてます。」「『機器構成名リスト』シートを確認してください。」を空行を挟んで追記する。
作業者操作＝両版の通知全文を控えて「OK」を押す。改修版の接続・取得方式の途中表示と現行版を文字一致させる必要はない。
```

### 備考
全行の全列比較ではない。現行版が実行できない、DBが違う時点、マスタ版不一致の場合は理由を記録して実施不可とする。
