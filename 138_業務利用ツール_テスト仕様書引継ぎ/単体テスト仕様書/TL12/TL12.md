# TL12（見積実績検索） 単体テスト仕様書

対象：見積実績検索ver1.2.xlsm（改修版）。シート「問合せ」で機器型式・機器品名・製造メーカ・見積時間を入力して「問合せ実行」を押すと、新MCM（SQL Server）から状態が見積の取引先見積を探し、10行目から下に12列で表示する。DBは読むだけで、更新しない。

凡例：
- 実施者：試験を行う人。Excelでツールを実行し、シートの表示を確認する。
- 準備担当者：試験データを新MCMに登録し、試験データ表に値を書いて実施者に渡す人。
- 試験データ表：準備担当者が、登録した取引先見積の12列の値を書く表。各ケースの前提条件にある。
- 各ケースの「前提条件」「操作内容」「期待結果」は、そのケースだけを読んで実施できるように書いてある。他のケースは参照しない。
- 試験データの準備は準備担当者の役割とし、実施区分の判定には含めない。
- このツールにはメッセージIDがないため、期待メッセージの「メッセージID」は「－」とする。
- 実施区分：通常／要確認／開発者テスト／実施不可／除外候補（test-spec-common-rules.md 14.7章）

項番の欠番：

| 項番 | 理由 |
|---|---|
| 004 | 検索条件がないときのメッセージ。マクロの処理が TL11（店舗見積実績検索）と同じため、TL11-005 で確認する（作成者承認 2026/11/02） |
| 005 | 接続エラー。マクロの処理が TL11 と同じため、TL11-007 で確認する（作成者承認 2026/11/02） |

## TL12-001

### 項番
TL12-001

### テスト項目
TL12(見積実績検索)：機器型式1に型式の一部を小文字で入力すると、大文字・小文字を区別せずに部分一致で探し、状態が見積の取引先見積だけが12列で、決まった順に表示されること

### 前提条件
```
【この試験で確認すること】
機器型式1に型式の途中の文字を小文字で入力して「問合せ実行」を押すと、その文字を含む型式の取引先見積が、大文字・小文字を区別せずに表示されること。状態が「見積」の取引先見積だけが表示され、「契約」の取引先見積は表示されないこと。12列の値が試験データと一致し、ﾊﾟｯｸ契約の小さい順、同じﾊﾟｯｸ契約の中では見積作成日の新しい順に並ぶこと。

【実施する人】
・実施者（試験を行う人）
・準備担当者（試験データを新MCMに登録する人）

【実施者に必要なもの】
・Excel（マクロを有効にできること）が入ったPC。
・改修版のフォルダー「12_見積実績検索」一式を、PCにコピーしてあること。フォルダーの中の「Mcm移行部品」フォルダーも、同じ位置関係のままコピーする。
・OLE DB ドライバー（MSOLEDBSQL19）が、PCに入っていること。
・環境変数 MCM_MACRO_DB_USER、MCM_MACRO_DB_PASSWORD が、実施者のアカウントに設定されていること（設定は依頼元に聞く。値はこの仕様書に書かない）。
・接続先が本番ではないこと（依頼元に確認済みであること）。

【準備担当者が用意するデータ】
新MCMに、取引先見積を4件用意する（以下、見積A、B、C、D）。各見積には、契約時間が1つ、機器明細が1件あり、その機器明細に、その契約時間の期間の単価が登録されている。
・型式：ほかの取引先見積に出てこない半角の英数字を含める。見積Aは「TL12TEST-A」、見積Bは「TL12TEST-B」、見積Cは「TL12TEST-C」、見積Dは「TL12TEST-D」とする（大文字で登録する）。登録前に、DBの既存データにこの文字を含む型式がないことを確認する。
・状態（契約時間の状態）：見積A、B、Dは「見積」。見積Cは「契約」。
・ﾊﾟｯｸ契約：見積A、Bは0。見積Dは0以外の値（例：1）。
・見積作成日：見積Aは見積Bより古い日付にする。見積Dは見積A、Bのどちらよりも新しい日付にする。月と日の少なくとも一方は1桁にする（例：見積A＝2026/09/01、見積B＝2026/09/15、見積D＝2026/10/05）。
・サポートID：見積Aは、先頭が「0」のサポートIDの取引先見積にする。
・標準価格、仕切金：見積ごとに違う値にする。
・見積時間（保守契約時間帯）：指定しない（どの値でもよい）。
登録が終わったら、見積A〜Dの12列の値を、下の「試験データ表」に書いて実施者に渡す。値は、新MCMの画面かDBで確かめた値を書く。

試験データ表（準備担当者が記入する）：
| 見積 | サポートID | 出荷先名 | 見積作成日 | 取引先見積依頼No | 保守契約時間帯 | 取引先名 | 製造メーカ | 品名 | 型式 | ﾊﾟｯｸ契約 | 標準価格 | 仕切金 |
| A | | | | | | | | | TL12TEST-A | 0 | | |
| B | | | | | | | | | TL12TEST-B | 0 | | |
| C | | | | | | | | | TL12TEST-C | | | |
| D | | | | | | | | | TL12TEST-D | | | |

【開始時の状態】
Excelを起動していなくてよい。
```

### 操作内容
```
1. エクスプローラーで、コピーしたフォルダー「12_見積実績検索」を開く。「Mcm移行部品」フォルダーの McmMacroSettings.ini をメモ帳で開き、「Server=ILCM-SYSDEV」「Database=SYSDEV」と書かれていることを確認する。変更せずにメモ帳を閉じる。

2. 「見積実績検索ver1.2.xlsm」をダブルクリックで開く。画面上部に、マクロを有効にするかを尋ねる黄色の帯が出た場合は、帯のボタンを押下して有効にする。

3. シート「問合せ」を選ぶ。C2〜C7（機器型式1〜見積時間の入力欄）を選び、Deleteキーを押して、すべて空にする。（保存されたブックでは、C2に「C332dNw」、C4に「(a3」が入っている。）

4. C2（機器型式1）を選び、「l12test」（すべて小文字）と入力して、Enterキーを押す。

5. 「問合せ実行」ボタンを押下する。画面左下の表示が「準備完了」に戻るまで待つ。

6. 10行目から下の表示を、試験データ表と照合する。保守契約時間帯、ﾊﾟｯｸ契約、標準価格、仕切金の列は、セルを選んで、数式バーに出る値で照合する。見積作成日の列は、セルの表示と、数式バーに出る値の両方を見る。

7. Excelを閉じる。保存するかを尋ねられた場合は、保存しない方のボタンを押下する（ツールのブックを変えないため）。

【入力値】
・機器型式1（C2）＝l12test
・機器型式2、機器品名1、機器品名2、製造メーカ、見積時間（C3〜C7）＝空欄
```
