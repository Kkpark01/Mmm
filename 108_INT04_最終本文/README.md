## 最終用語照合での補正

- MCM2006Uには個体名・シリアル番号が表示されないため、契約画面の機器は「機器構成名」「品名」「型式」「数量」などで照合する。個体の選定はMCM2007Uの《機器個体毎の明細》で確認する。
- 04の採用個体数1件・2件はMCM2007Uで確認し、MCM2006Uでは構成の「セット数」を確認する。
- 06の除外個体が保存対象から外れたことは、最新期間に限定したDB担当者の確認へ分けた。画面の備考・日付・構成明細の表示を確認し、存在しないシリアル番号列を探させない。
- 19は採用機器を変えず、未登録案の開始日・終了日とタブ数だけで置換を確認する。シリアル番号の入替えを契約画面で確認する旧案は使わない。
- MCM3004U「不足製番確認」の一覧には契約番号列がないため、15は「サポートID」「納入先名」「プラント名」「保守金額」で対象行を照合する。準備担当者がその組合せで対象行を特定できることを確認する。
- 製番は省略せずINT04HW01／INT04SW01、INT04HW02／INT04SW02と表記し、13→17の引継ぎを揃えた。
- 編集画面で選ぶ見積NOを準備値に含めた。テスト実施者に「対象見積」がどれか判断させない。

確認根拠は`mcm2004u/index.html`、`mcm2006u/index.html`、`mcm2007u/index.html`・`step2.html`、`mcm3008u/index.html`、`mcm3004u/index.html`の該当画面・一覧、`MenuService.java`のメニュー名。期待メッセージはVB `CPMessage.xml`と照合した。コード中の内部名をそのまま画面項目名として使っていない。
