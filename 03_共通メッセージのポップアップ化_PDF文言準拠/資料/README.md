# 03 共通メッセージ修正の資料一式

03の共通化に関するMarkdown資料を検証記録からコピーしました。原本は検証記録にも残しています。

| 資料 | 内容 |
|---|---|
| [全画面メッセージ表示_調査結果.md](全画面メッセージ表示_調査結果.md) | 修正前の全画面調査と表示方式の確認。 |
| [修正対象と文言の修正前後_PDF準拠案.md](修正対象と文言の修正前後_PDF準拠案.md) | PDFに基づく修正対象・文言の比較案。 |
| [遷移影響の追加確認.md](遷移影響の追加確認.md) | 実装後の画面遷移への影響確認と検証範囲。 |
| [反映手順.md](../反映手順.md) | 03の実装内容、適用順序、確認結果、制約。03フォルダ直下にあります。 |

調査結果・比較案には修正前の状態や計画も含まれます。最終的な実装範囲は「反映手順.md」を参照してください。

資料内の「検証記録/...」はMCMフォルダからの相対パスです。検証用ログ・JSON・画像は引き続き検証記録に保存しています。
本番へ反映するのは03フォルダ内のsrcです。この資料フォルダは説明用です。
