# MCM2002U 機器選択連動の修正

最新版src（2026/09/17受領）用。元のmcm-web/srcは変更していません。
このフォルダのsrc内の2ファイルを、同じ相対パスへ上書きしてください。

## 修正内容

- Java側：再選定時、同じ機器IDでもBigDecimalの桁数（10／10.00）が異なると個体のチェックが外れる問題を修正。明細は構成IDとの組合せで判定します。
- 画面側：桁数が異なるIDでも、明細・個体の表示とチェック連動を維持。大きなIDをJavaScriptのNumberへ変換せず、丸めを避けています。
- 構成の一括選択：選択可能な親明細に属する個体だけを選択します。VB版のMCM_TM_KIKIKOSEIDataGridView_CellContentClickにある、親明細の選択可否を踏まえた連動に合わせています。
