- A列の項番、B列の分類、H～O列の実績・最終判定は維持します。今回の添付では対象5項目はいずれも最終判定「未実施」です。
- その他のケースと対象外区分は変更しません。02-04本体の変更案でもありません。

## 準備担当者への補足

- 検索番号、期間開始日、権限、申請済みの状態を揃えた試験データを実施者へ渡してください。点検・支払の回数と月チェック、契約期間などの申請条件は準備時に確認し、実施者に条件の組み立てを任せない構成です。
- 07は差戻し後に同じ資料で再申請します。対象期間に承認済み資料を混在させないでください。以前の承認済み資料を保護する確認は14、承認段階の差戻し後に審査から再開する確認は08へ分担します。
- 10は既存の正常なxlsx原紙を使い、先頭が「契約手続依頼書①」の対象シート名と、審査欄・承認欄の位置を実施者に知らせます。元仕様の図形名（`stp_lastname`、`stp_date`、`stp_firstname`、`stp_circle`、`stp_topline`、`stp_btmline`、`shinsa_lastname`、`shinsa_date`、`shinsa_firstname`、`shonin_lastname`、`shonin_date`、`shonin_firstname`）の確認は準備担当者が行います。実施者が原紙を加工する手順はありません。原紙が未確認なら10は準備待ちです。
- 10の審査後・承認後の取得先は別の空フォルダとし、取得したファイルを混同しないようにします。
- 11のxlsxには「契約手続依頼書①」で始まるシートを含めず、原本と取得後のシート名・識別文字・押印の有無を見比べられるようにします。ファイルの全バイト一致や、全セルの不変を確認したとは扱いません。
