# #304 動作確認手順

## 準備

01（#301）と02（#304）を反映し、ビルド・再起動を済ませます。登録してよい検証用プラントを使ってください。

取扱機器マスタのコントローラフラグがONの機器を用意します。「○ コントローラ」という表示名だけでは、フラグがONであることを保証しません。不具合が起きた機器を使う場合は、そのフラグも確認してください。

## 1. 設定直後の自動ON

| 手順 | 操作 | 期待結果 |
|---|---|---|
| 1 | MCM0010Uから対象プラントの「機器構成」を開く。 | MCM0013Uが表示される。 |
| 2 | コントローラがOFFの対象構成を確認し、「選択」を押す。 | MCM0014Uが開く。 |
| 3 | コントローラフラグがONの機器を検索する。 | 対象の品名・型式を確認できる。 |
| 4 | 対象機器の「選択」を押して明細へ追加する。 | 明細に機器が追加される。同じ分類等が既に存在する場合は、別の検証用構成を使う。 |
| 5 | 必要項目を入力し、「設定」を押す。セット数は変更しなくてよい。 | 13Uへ戻る。 |
| 6 | 対象構成のコントローラ欄を見る。手動でチェックしない。 | 自動でチェックがONになっている。他の構成のチェックは変わらない。 |

手順6の直後に、対象構成名・チェック・下段明細が分かるスクリーンショットを残してください。
登録済み構成と、行追加で作成した新規構成の両方で確認します。

## 2. 登録・再表示

1. 個体のNo・取引先・ブランド等の必要項目を入力します。他の構成にも数量不一致や入力漏れがないことを確認します。
2. 「登録」を押します。
3. 「登録を実施します。よろしいですか？」のOKを押します。
4. 「登録を完了しました。」のOKを押します。
5. 同じ構成のコントローラがONで、個体行数と入力内容が維持されていることを確認します。

## 3. 既存エラーチェック

1. 有効なコントローラ明細がある構成で、構成側のチェックを手動でOFFにします。セット数は変更しません。
2. 「登録」を押します。
3. 「機器構成情報のコントローラが有効ではありません。」が表示され、登録されないことを確認します。
4. 確認後はチェックをONへ戻します。

## 4. 非コントローラの確認

コントローラフラグがOFFの機器を、別のOFF構成へ設定します。構成側が勝手にONにならないことを確認します。
分類表示が○でも、取扱機器のコントローラフラグがOFFなら、この修正ではONにしません。
