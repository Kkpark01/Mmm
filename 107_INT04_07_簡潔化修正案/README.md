## 判断と変更理由

07は期間の途中の日付を指定する通常の「変更」機能に対応する。画面・コードに経路があり、05（終了日の翌日からの追加）・06（未来期間の機器更新）とは条件が違う。実運用で使わないと確認できる資料は、今回参照した範囲では見つからなかった。

106で旧手順ごと対象外とした案を見直し、通常操作1条件の簡潔な確認として残すことを推奨する。機器は各1件のまま変更せず、開始日だけを実施日の翌日とし、終了日は延長しない。5手順で登録と再表示を確認し、DBは期間だけを照合する。

入力できない旧期間の終了日を補正する旧手順は戻さない。利用者の「VB版で作成できる構成なら問題ない」という明確化を受け、旧期間終了日の自動調整を必須とする条件も外した。07は新期間の追加・登録・再表示と機器の保持に限定する。旧期間の日付は記録に留め、VB／Webの調整差が解決したとは報告しない。

実際の業務で途中変更を使わないことが確認できた場合は、未使用という業務上の理由で対象外にできる。未使用という判断をコードから推測していない。
