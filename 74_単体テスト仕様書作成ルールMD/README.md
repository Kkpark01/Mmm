## 別AIへの渡し方

この一式に加え、対象ID・対象種別・最新WebとVBソース・承認済み設計／移行／共通仕様・メッセージと入力検査定義・DB定義・基準単体Excel・既存単体／結合／帳票仕様書を渡します。Excel／ソースはこのZIPには含めていません。

結合用73を単体の主ルールとして同時適用しないでください。単体の主ルールは74とし、他工程の分担を確認する際だけ結合用を参照します。どちらも利用者の指示・承認済み仕様・基準Excel実物を優先します。

## 作成・確認範囲

既存作成ルールを参考に単体用へ書き直しました。受領契・解約単体261002版の1005U／3004Uの16列・見出し位置の差を確認し、構成を固定しない方針としました。これらの確認値は例であり、原本仕様書の機能期待を全件検証した意味ではありません。

入力境界、UI／サーバー検査、重複エラー中止、3一覧の適用確認、分岐対応表、他工程分担、順序、VB不整合、実績区別、Excel集計・表示を含めています。文書内の参照・リンク・MD表構造・必須観点・ZIP内容を確認しました。

このルールがあれば自動的に全機能を保証できる、というものではありません。個別仕様書の完成時は、その画面の根拠と対応表・完成Excelを確認してください。73、参考MD・Excel、VB・アプリsrcは変更していません。
