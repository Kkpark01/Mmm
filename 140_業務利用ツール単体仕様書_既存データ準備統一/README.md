# 業務利用ツール単体テスト仕様書：既存データでの準備に統一

**今後使うMDはこの140。元の138は受領・作成履歴として残した。** 16ツール・76ケースを一式で収録し、準備方針と、それに依存する入力・期待値を整合させた。修正コードやマクロ本体を差し替えるフォルダーではない。

## 主な変更

- TL01・11・12の「指定の見積を新規登録」「数量2・1・1」「架空の品名・型式で3件・2件表示」をやめ、既存値・全期待集合で判定する。
- 検索語が一致する他の既存行も期待件数へ含める。必要な代表条件が1つの検索で揃わなければ、別の既存セットで補完できる。
- 比較試験は固定の過去番号・固定月ではなく、両DBで選定・照合した値を使う。
- 前回結果の消去試験は、配布ブックに表示が残っている前提にせず、既存値で正常取得して保存したコピーを準備する。
- SQL認証時の環境変数とWindows認証を区別し、接続先は準備記録と一致させる。

対象データを確認できていないため、入力値欄を架空の値で埋めていない。共通方針と本文の表へ、準備担当者が実在値と期待値を記入する。条件不足を合格扱いしない。

## 確認結果と制約

文書の構成・ケースID・リンク・入力変数と期待値の対応を確認。138のMDと、131等のマクロ・EXE・設定・原紙は変更していない。実DBへの接続・新規登録・更新・業務マクロ実行、Excel化は行っていない。

文字比較の修正反映、比較範囲、TL11-002、TSSA等は今回とは別の残件。準備を統一しただけで移行全体を完了したとは判定しない。詳細は進捗表を参照。
