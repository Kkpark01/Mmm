# TL03（契約手続依頼書発行） 単体テスト仕様書

準備方針：[共通方針と準備記録](../00_試験準備の共通方針.md)。このケースで使う既存入力値・期待件数・対象版を準備担当者が記入する。DBの試験データ新規登録は行わない。

対象：契約手続依頼書発行ver3.3.xlsm（改修版）。操作シート「取引先契約手続依頼書発行」に契約番号などを入れて、「新規契約」「解約依頼」「契約更新」のボタンを押すと、新MCM（SQL Server）から取引先契約のヘッダと機器明細を取り出し、テンプレートに写して、取引先向けの手続依頼書（.xls）をツールと同じフォルダーに保存する。DBは読むだけで、更新しない。

凡例：
- 実施者：試験を行う人。Excelでツールを実行し、操作シートと依頼書を確認する。
- 準備担当者：検証DBにある取引先契約から試験用の契約を選び、試験データ表に値を書いて実施者に渡す人（新しく登録はしない）。
- 試験データ表：準備担当者が、選んだ取引先契約の値を書く表。各ケースの前提条件にある。
- 依頼書：このツールが作るExcelファイル（.xls）。1ページ目のシート名は「契約手続依頼書①」。
- 依頼書のセルの位置は、TL03\用語表.md 8章による。テンプレートのラベルの文字は調査で読めていないため、実施のときに記録する。
- 各ケースの「前提条件」「操作内容」「期待結果」は、そのケースだけを読んで実施できるように書いてある。他のケースは参照しない。
- 準備担当者が既存データを選定する。準備未完のケースは開始せず、未確認を合格へ読み替えない。
- このツールにはメッセージIDがないため、期待メッセージの「メッセージID」は「－」とする。
- 実施区分：通常／要確認／開発者テスト／実施不可／除外候補（test-spec-common-rules.md 14.7章）

## TL03-001

### 項番
TL03-001

### テスト項目
TL03(契約手続依頼書発行)：「新規契約」で、契約手続依頼書が決まった名前で保存され、ヘッダの支払条件、時間帯、担当者の敬称と、機器構成ごとの明細が出ること

### 前提条件
```
【この試験で確認すること】
操作シートに契約番号を入れて「新規契約」を押すと、契約手続依頼書（.xls）が、ツールと同じフォルダーに決まった名前で保存されること。依頼書の上部（ヘッダ）に、取引先・納入先・契約金額・契約開始日が出て、支払条件が「年n回　月」の形に、時間帯に「H」が、担当者名に「 様」が付くこと。明細が機器構成ごとに分かれて出ること。

【実施する人】
・実施者（試験を行う人）
・準備担当者（検証DBから試験用の取引先契約を選び、試験データ表を渡す人）

【実施者に必要なもの】
・Excel（マクロを有効にできること）が入ったPC。
・改修版のフォルダー「01_契約手続依頼書」一式を、PCにコピーしてあること。中の「Mcm移行部品」フォルダー、「【テンプレート】契約手続依頼書.xls」、「特記事項テンプレート .xlsx」も、同じ位置関係のままコピーする。
・OLE DB ドライバー（MSOLEDBSQL19）が、PCに入っていること。
・SQL認証の場合のみ、MCM_MACRO_DB_USER・MCM_MACRO_DB_PASSWORDを実施者の環境に設定する。Windows認証では不要。認証情報は本書へ書かない。
・接続先が本番ではないこと（依頼元に確認済みであること）。

【準備担当者が用意するデータ】
検証DBにある取引先契約から、次の1件を選ぶ（新しく登録しない。以下、契約D）。
・状態が「契約」。有効な期間がある。
・支払回数が12以外（例：年4回）で、支払明細の月と回数が合っている。
・取引先の担当者名と、納入先の担当者名の末尾に「様」が付いていない。
・機器構成が2つ以上あり、個体管理する機器（シリアル番号あり）を含む。
・明細の行数（機器構成の見出しを含む）が20行以内（1ページに収まる）。
選んだら、下の「試験データ表」を書いて実施者に渡す。値は、新MCMの画面かDBで確かめた値を書く。

試験データ表（準備担当者が記入する）：
| 項目 | 値 |
| 契約番号 | |
| サポートID（7桁） | |
| 取引先名、取引先担当者名 | |
| 納入先名、工場名、納入先担当者名 | |
| 契約金額（期間の仕切合計金額） | |
| 初回契約日 | |
| 契約時間帯 | |
| 支払回数と、支払明細の月 | |
| 機器構成名（表示順に） | |
| 機器構成ごとの機器（品名、型式、数量、シリアル番号） | |

【開始時の状態】
Excelを起動していなくてよい。コピーしたフォルダー「01_契約手続依頼書」に、「_契約手続依頼書_」を含む名前のファイルがないこと（あれば別の場所へ移す）。
```

### 操作内容
```
1. エクスプローラーで、コピーしたフォルダー「01_契約手続依頼書」を開く。「Mcm移行部品」フォルダーの McmMacroSettings.ini をメモ帳で開き、サーバー名・DB名が準備記録の検証接続先と一致することを確認する。変更せずにメモ帳を閉じる。

2. 「契約手続依頼書発行ver3.3.xlsm」をダブルクリックで開く。画面上部に、マクロを有効にするかを尋ねる黄色の帯が出た場合は、帯のボタンを押下して有効にする。

3. シート「取引先契約手続依頼書発行」を選ぶ。C3（見積No（契約書No））を選び、試験データ表の契約番号を入力して、Enterキーを押す。（保存されたブックでは「2104-007」が入っている。上書きする。）

4. 「新規契約」ボタンを押下する。メッセージが表示されたら、内容を確認して「OK」を押下する。

5. 作られた依頼書が、別のウィンドウで開いている。シート「契約手続依頼書①」の上部と、27行目から下の明細を確認する。

6. ツールのウィンドウに切り替え、シート「取引先契約手続依頼書発行」のF3〜F6を確認する。

7. エクスプローラーで、フォルダー「01_契約手続依頼書」の中を確認する。

8. 依頼書とツールを閉じる。保存するかを尋ねられた場合は、どちらも保存しない方のボタンを押下する。依頼書のファイルは、試験の記録として残す。

【入力値】
・見積No（契約書No）（C3）＝試験データ表の契約番号
```

### 期待結果
```
【画面確認】
1. 手順4で、期待メッセージのメッセージが表示される。
2. 手順6で、F3＝試験データ表の取引先名、F4＝サポートID（7桁）、F5＝納入先名、F6＝契約番号。

【ファイル確認】
1. 手順7で、フォルダー「01_契約手続依頼書」（ツールと同じフォルダー）に、次の名前のファイルがある。
　サポートID（7桁）＋「_」＋納入先名（「株式会社」「有限会社」を除く）＋「_契約手続依頼書_」＋契約番号（「/」は「,」に置き換え）＋「_date」＋実行した日時（年月日8桁＋「_」＋時分秒6桁）＋「.xls」
2. 手順5で、シート「契約手続依頼書①」の上部が次のとおり。
　F1＝「■新規契約」を含む（「□新規契約」ではない）
　P1＝「作成日：」＋実行した日（YYYY/MM/DD）
　D3＝取引先名、D4＝取引先担当者名＋「 様」
　D6＝納入先名＋半角スペース＋工場名、I9＝納入先担当者名＋「 様」
　D10＝サポートID（7桁）
　D12＝契約金額、D13＝初回契約日（同じ日付）
　D14＝契約時間帯＋「H」（例：8H）
　I12＝「年」＋支払回数＋「回」＋全角スペース＋支払明細の月を「、」でつないだもの（例：年4回　1月、4月、7月、10月）
　I13＝契約番号
3. 27行目から下に、試験データ表の機器構成ごとに「◆」＋機器構成名の行があり、その下にその機器構成の機器（品名、型式、数量）が並ぶ。個体管理する機器の行には、シリアル番号が「S/N： 」に続けて出る。依頼の欄は「○」である。

【DB確認】
実施不要（このツールはDBを読むだけで、更新しないため）。
```

```
表示タイミング＝手順4で、「新規契約」ボタンを押下し、依頼書が保存されたとき
```
