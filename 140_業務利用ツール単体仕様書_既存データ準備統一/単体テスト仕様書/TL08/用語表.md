## MCM取得

| 入力・表示 | 内容 |
|---|---|
| G14 | 契約No。複数指定は半角スペース・スラッシュ・半角スペースの「 / 」で連結 |
| G16 | サポートID。入力は必須。先頭0を含む値を保持 |
| TMP_SQL!C4:C13 | 分割した契約No、最大10件。未使用欄はNULLでSQLへ渡す。C2のサポートIDは今回のSQLの絞り込みには使わない |
| 点検依頼対象 | 1行目見出し、2行目以降13列。M列は機器管理ID。M列で重複除去 |
| メーカー別作成シート | K2:V2の12列が見出し、K3:V以降が取得結果。機器管理IDはこの一覧へ転記されない |

SQLはT22_00_default_01.sql。契約No10パラメーター、採用する契約期間、点検回数、機器分類で取得する。サポートIDのみで対象を絞る期待値にしない。契約があるだけでは点検対象の取得を保証しない。

| 表示列 | 見出し |
|---|---|
| K | 取引先契約状態 |
| L | サポートID |
| M | 製造メーカー名 |
| N・O | 納入先名・納入先住所 |
| P・Q | ブランド詳細名・機器構成名 |
| R・S・T | 機器品名・機器型式・シリアル番号 |
| U・V | 個体名・メーカ契約No |

M列のメーカー名に作成シートF1の文字列が含まれない行がある場合、メーカー相違の可能性を知らせる通知を出す。その後、抽出完了通知を出す。取得エラーや自動中止ではない。

**旧結果のクリアは要確認。** Start_UserInfoはT列（シリアル番号）の最終行までしかK:Vを消さない。末尾T列が空欄の場合に旧結果が残ることを、同じ範囲操作のダミーExcelで確認した。受領原本にも同じ処理がある。003では正しい期待「旧結果が残らない」を維持し、実装差があることを明記する。[整合レビュー](../../整合レビュー_20261102.md)参照。

## 帳票と住所取得

**MCMのK:V一覧は、現行の帳票作成処理の自動転記元ではない。** 帳票の基本情報は作成シートG列、機器明細は貼付エリアE32以降を使う。MCMの取得結果が帳票へ自動的に反映されるという手順は作らない。

| 項目 | 入力・参照先 |
|---|---|
| 原紙パス | メーカー別作成シートG3 |
| 出力フォルダー | 同G5。初期式はメインページG6を優先し、空ならC6 |
| 出力ファイル名 | 同G7。試験では既存ファイルと重ならない名前を使う |
| 客先名・住所・契約No・サポートID | 同G10・G12・G14・G16 |
| TSSAのパス | INIのReference_TSSA。未指定時はDownloads内の固定ファイルへフォールバック |
| TSSA内のシート・列 | TSSA20260129シート。A列サポートIDの完全一致でG列住所を取得し、貼付エリアE14へ転記 |
| Notes由来の照合元 | ブック内「ハードウェア点検・予防保守作業」。B列年月、H列メーカー、I列サポートIDを貼付エリアの条件と照合 |
| 転記先の原紙シート | 【原紙】保守作業依頼書 |

Reference_TSSAはファイルの場所の設定。内部シート名も自動で変わる機能ではない。TSSA原本は今回手元にないため、パスの到達性・上記シート名と列構成を実施前に確認する。

原紙7点は131の10／依頼書テンプレートへ配置済み。代表NEC原紙を、マクロ無効・読み取り専用で開き、対象シートとF4～F16、E34～E37の結合範囲を確認した。帳票の実生成・7原紙すべてへの転記確認ではない。パスワードは手順やエビデンスへ転記しない。

出力処理は原紙をG5＋G7へ複写して開き、内容を書き込む。**処理結果は自動保存しない。** 「依頼書の作成が完了しました。」の後、出力ブックへ切り替えてCtrl＋Sで保存し、閉じて再度開いて確認する。試験用マクロ本体を保存する操作と混同しない。

代表NECの主な転記先：F4客先名、F5住所、F6契約No、F7サポートID、F9日程、F10開始時間、F11終了時間。最初の機器はE34構成名、E35品名、E36型式、E37シリアル番号。貼付エリアE32の「 / 」で区切った4項目を使う。4項目を持たない任意の文字列で試験しない。

代表NECの保存済みシートには、G10等のXLOOKUPによる整形済み入力とG32のendマーカーがある。004ではこの既存形式を使い、「①左から文字編集」は押さない。同ボタンはコロン付きの未編集入力向けで、整形済みの氏名・住所を再編集すると値を消す可能性がある。会社版で入力形式を変えている場合は、同じ手順を無条件に適用せず確認する。
