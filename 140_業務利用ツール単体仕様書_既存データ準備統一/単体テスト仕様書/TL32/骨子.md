# TL32（保守状況報告データ抽出） 骨子

137のコードを根拠に本文8件を作成。DB当日の全対象を集計するため、年月・店舗指定は作らない。

| 項番 | 目的 | 準備・確認先 |
|---|---|---|
| 001 | 新規出力・3集計 | 全店舗期待表、原紙行、B2・E4:G91・E92:G92・ログ |
| 004 | 上書きはい | 試験用既存帳票の識別文字を当日期待値へ置換 |
| 005 | 上書きいいえ | 取得後の取消、既存出力・原紙不変、ログは追記 |
| 006 | 現行比較 | 同時点の両DBと原紙・実出力の取得経路 |
| 007 | 原紙不足 | 専用コピーの原紙だけ退避、通知・出力なし |
| 008 | 開始いいえ | 取得・保存・ログ追記なし、初期状態保持 |
| 009 | 終了確認 | いいえで継続、はいで終了 |
| 010 | 店舗対応不一致 | 専用原紙のD列を空欄、既存帳票保持、異常ログ |

002は検索条件の機能がないため対象外。003相当の全体0件は、通常の共有検証DBに条件を作れないため開発者の独立環境へ割当て。期待は月設定・明細空欄・合計0・ログ0店舗。共有DBの契約を削除・無効化しない。

日付境界、最大ID、重複／NULLサポートIDは001の代表に既存データがあれば含める。なければ独立テストへ割当て。店舗の複数一致、15桁超、金額NULL・小数、出力先使用中、保存後のログ失敗も独立テストへ割当てる。137の既存36項目とExcel再読込検証を参照するが、今回の会社実機試験済みとはしない。

他画面からの契約変更・期間切替の反映、並行更新、後続業務への帳票受渡しは結合へ移管。店舗照合の大小文字・全角半角と、DBのGROUP BY単位を混同しない。印刷ページ数は固定せず会社の原紙と比較する。

[確認観点対応](../TL30-32_確認観点対応.md)に実施先と終了条件を記載。原紙・実行用は変更していない。
