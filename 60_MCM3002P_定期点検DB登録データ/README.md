## 確認方法

1. メニューで「保守点検出力指示（MCM3003U）」を開く。
2. データのある「点検対象月」をYYYY/MMで開始・終了に指定し、「全件出力」を選ぶ。
3. 「ＤＢ登録用データ」を押し、`開始月_終了月_全件_定期点検DB登録データ.xls`を開く。登録ボタンの操作やDBへの登録は不要。
4. 納入先・点検月・サポートIDと機器が欠けていないことを確認。同一プラント・月・曜日の機器は5件ずつ横展開し、5件の行に●、6件目は次の行に出る。
5. 「差分出力」では出力対象日付を指定して同様に取得。開始のみ／終了のみも許容する。検索結果0件や不正な日付では通知を閉じた後、条件を修正して再試行できる。
