## 最初に行う軽い作業

次は **1004Uの配置比較と表示調整だけ** に範囲を絞ります。登録や契約処理の改修は別の作業として扱います。納入先マスタ側へ範囲を広げず、契約・見積関連を優先します。

| 順序 | 作業 | 完了の目安 |
|---|---|---|
| 1 | VB Designer・画面処理・共通親画面から、項目順とボタン位置を表にする | VBの根拠ファイル・コントロール名を記録 |
| 2 | 現在のWebを撮影し、VBとの比較を1セットにする | 再構成画像は「VB実機ではなくDesigner再構成」と明記 |
| 3 | 外周、タイトル、ラベル間隔、行高を画面専用CSSで調整する | 外周8px、紫#453f78、タイトル高さ40px・文字18px、通常行24pxを基準に実画面確認 |
| 4 | ボタンと《》見出しを照合する | 《》は保持。見出しのグレー背景・囲みを付けない。ボタン位置は共通親画面も確認 |
| 5 | 3007Uから開く・戻る操作を確認する | 選んだ依頼のIDと表示内容、戻り先、検索条件を確認。失敗したら記録し、表示修正の成功と区別 |

行高や列幅は入力部品が収まることを優先し、全要素を一律に固定しないでください。比較画像をユーザーへ提示してから次の画面に進みます。

1004Uでは受領Webの見出しが「需要家契約一覧」となっています。説明上の「見積依頼内容」と同じとは決めつけず、VBの画面タイトルと照合して判断してください。

## 軽い作業と混ぜない残件

これらは残っています。資料整理によって解決したわけではなく、簡単な見た目修正として完了扱いにしないでください。

| 残件 | 必要な確認 |
|---|---|
| 1004U・1005U・1006Uの業務処理 | VBと保存先・権限・状態・入力保持を照合。特に1006Uは3007Uから接続した段階で、登録完了まで未確認 |
| 本番SQL Server | 実際のビュー・列型・検索・保存・ロールバック、追加SQLの適用を検証環境で確認 |
| 実メールとSPモード | SMTP設定・実配送、SQL Serverでのプロシージャ作成と実行。送信先や実行環境を明確にして確認 |
| 帳票 | 元Excelテンプレートを入手できれば再構成書式と照合。現状は完全一致を未確認 |
| 3007Uのプラント別権限 | VBの `mcm_fn_kengenLink` とWebの画面権限による表示制御の差を照合 |
| 3007Uの取引先の時間順 | `Mcm3007uRepository.searchTka` は `ORDER BY V.TM_IRAI_NO DESC,V.KEIYAKUJIKANTAI`。列型とVBの数値順を照合し、8・24等の順序差の有無を確認してから修正 |
