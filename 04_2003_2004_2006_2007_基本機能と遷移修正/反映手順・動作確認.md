# 2003・2004・2006・2007 基本機能と遷移の優先対応

2026-09-11受領の「src (2).zip」を基準にした修正パッケージです。既存見積の編集・申請、承認済み見積からの契約作成、契約期間の変更、画面間の入力保持を優先して修正しました。VB版の全機能の移植完了を示すものではありません。

`src` 内の21ファイルが反映対象です。既存18ファイルの変更と新規3ファイルを含みます。作業用の `mcm-web/src` は受領した478ファイルをそのまま保持し、本番環境への反映は実施していません。

VBのテーブル定義・DataSetのSELECTを参照し、見積番号・承認状態、契約ヘッダーと期間の連絡先、機器の親子関係、見積と契約ブランドの関連、個体の納入日、月別点検の参照先を見直しました。

## 反映手順

1. 反映先のソースを退避します。基準は2026-09-11受領版です。それ以降の変更がある場合は、同梱の `差分一覧.json` の元ファイルSHA256と比較して差分を統合します。
2. このパッケージの `src` を、反映先の `mcm-web/src` に同じ相対パスで重ねます。src全体の置き換えではなく、対象21ファイルの追加・上書きです。
3. Java 21で既存のビルド手順を実行し、検証環境へ配置します。今回のためのDBテーブル追加やDDLの反映はありません。
4. アプリケーションを再起動し、ブラウザでログインし直します。更新前の編集中セッションは引き継がず、一覧から開き直します。
5. 下記の操作を、検証用データで確認します。

添付資料は既存の設定キー `mcm.file.upload-path` 配下の `estimates/見積ID/UUID/ファイル名` に保存します。実行アカウントが読み書きできる保存先を指定し、複数サーバー構成では共有できる場所を使用してください。アップロード容量はアプリケーションのmultipart設定に従います。

既存VBの添付をダウンロードするには、DBの `DIRECTORY` と `TENPUFILE_NK` が実際のファイルを指し、その実体が上記保存先配下にある必要があります。保存先外のファイルは配信しません。添付削除ではDBの関連を削除し、物理ファイルは復元用に残します。

新規ファイルは `CustomerScreenSupport.java`、`Mcm2003uAttachmentService.java`、`static/js/mcm2007u.js` の3つです。既存パッケージ02・03を今回のパッケージに重ねて作り直したものではありません。

## 操作確認

1. **2004→2003→2004**：検索して見積を開き、担当者・見積レベル・条件を変更して登録します。依頼元・送付先が消えないこと、戻ると条件を保って一覧が更新されることを確認します。
2. **2003の詳細遷移**：見積条件を未保存のままブランド詳細を開き、戻ります。条件が保持され、期間リンクでは選択ブランドと対象期間が渡ることを確認します。
3. **2003の添付・申請**：資料追加、ダウンロード、添付削除を確認します。添付なしの申請を拒否し、添付ありでは入力内容の保存と審査中への変更が一緒に行われることを確認します。
4. **2004→2007→2006**：承認済み見積の「作成」からブランド・期間・機器を選択して適用します。新しい期間が選択され、見積保守額と依頼元が入り、登録後の再表示でも機器・備考・連絡先が保持されることを確認します。
5. **2006→2007→2006**：変更摘要開始日を指定し、選択を変更します。「戻る→次へ」で選択が保持され、「キャンセル」では期間が追加されないことを確認します。適用時は前期間の終了日が変更開始日の前日になります。
6. **期間タブ**：備考を変更して別のタブへ移動し、元のタブへ戻って入力が残ることを確認します。登録後も両期間が残り、次回更新日が最終期間の終了日の翌日になることを確認します。
7. **参照・承認経路**：参照ユーザー、審査中・承認済み見積、3007から開いた契約で更新できないことを確認します。3007から開いた契約の「閉じる」は3007へ戻ります。
