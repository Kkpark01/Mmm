# 1004U 取引先見積内容：配置と基幹機能の修正

2026-09-12。表示調整の後、追加依頼に基づき、受領版に残っていた読み込み・保存・権限・タブ追加・照会を実装しました。同じ04フォルダを更新しています。本番には未反映です。

## 修正した機能

| 対象 | 修正後の動作 |
|---|---|
| 読み込み | 選択した見積のヘッダー、期間、単価、点検情報をVBと同じテーブル／ビューの関連から表示 |
| 登録 | 期間・単価・点検をまとめてINSERT／UPDATE。途中で失敗すれば全体をロールバック |
| 状態 | VBの依頼=0、見積=1、作成中=9に合わせ、依頼／作成中は登録後に見積へ変更。共通の状態定数は変更しない |
| 編集条件 | 画面別更新権限、状態、需要家見積への使用、取引先契約への使用、プラント一致、遷移元をサーバーで確認 |
| 管理者解除 | メンテナンス権限＋1004U更新権限が必要。利用者・見積・遷移元に限定し、権限取消後の保存を拒否。解除前に入力破棄を確認 |
| 同時更新 | 表示後に別の操作で親・期間・明細が変わっていたら保存を拒否し、再読み込みを案内 |
| タブ追加 | 入力途中の値も保持し、直前の期間の単価・点検・条件をコピー。開始日は前の終了日の翌日。保存時に別のIDを採番 |
| 期間変更 | VBの隣接期間チェックを基に開始日・終了日を連動。変更不可の日付は戻し、他の入力は保持。逆転・欠落・年上限を確認 |
| 選択項目 | 保守契約時間、保守方法、サービス形態、点検可能曜日を実装。DBの数値表現によって保存済みの時間が空欄になる問題も修正 |
| 金額 | 単価×数量、標準合計、仕切小計、出精値引き後の合計を再計算。ブラウザの小数計算には固定小数点、サーバーにはBigDecimalを使用 |
| 照会 | 選択した機器ID・取引先ID・時間帯を1007Uへ渡して別ウィンドウ表示。元の未保存入力は保持 |
| 戻る | 3007Uから開いた場合は閉じるで3007Uへ戻り、検索結果を保持。外部URLを戻り先に指定できない |
| 表示 | VBの上部4行、期間・金額、単価表、点検表、左下追加／右下登録を維持。表の登録・更新情報も追加。外周8px、紫タイトル40px・18px文字、通常行24px |

以前は保存処理にTODOがありました。今回は既存Service内の専用JDBC処理でVBの実列名に合わせました。既存の共有JPA Entity／Repositoryを変更せず、他画面への影響範囲を抑えています。入力からID・状態・数量・集計値をそのまま採用せず、サーバーが保持する対象行だけを更新します。

## 残る確認と意図的な差

- 本番SQL Serverでのビュー定義・列型・採番・ロック・認証インターセプターを含む一連の動作は未確認。検証用コピーへ04を重ね、会社の検証環境で保存・再表示を最終確認してください。
- VBの登録前に呼ばれるMCM_CLEAN_PAC.SP_TMは、対象IDで絞らず全見積の孤立データを削除する処理です。1004Uの登録操作に全件削除は移植していません。今回の保存は対象見積内のみ。既存の孤立データの全体清掃は別途扱います。
- VBは日付変更により次の期間が逆転し得る境界があります。Webでは有効な期間が残る範囲だけ許可します。
- 1003Uへの戻りはURLの許可のみ。1003U全体の再検証、1005U以降の全機能、1007Uの個別配置比較は未実施。
- これは確認した範囲の実装完了です。完全なVB一致や本番で不具合が一切ないことを保証する判定ではありません。
