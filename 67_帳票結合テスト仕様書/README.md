## 第3版：コードによる条件確定

52ケースを維持し、Excel「仕様書課題一覧」18行目以降とMDに、根拠付きの確定条件10項目を追加しました。ケースの前提・手順・期待結果にも反映しています。

- 点検差分はON日付で判定。新規ON／再ONと、ONを継続した曜日等の変更を区別。
- 金額4列は「取引先契約関連」のなし／参照／作成で判定。独立した金額表示設定という記述を訂正。
- 解約帳票は、編集可能な契約状態で解約日を入力して契約発行。状態が既に解約の場合の通常発行禁止と区別。
- プラント数別の複製経路、店舗選定・詳細設定、予定登録の遷移を具体化。
- 点検の翌年展開、支払対象の契約・期間・製番関連、契約差異・交換のSQL条件を明記。

Q01〜Q06には実サーバーの設定・共有権限、SQL Server実ビュー、実データ・権限マスタ登録、外部取込・管理者の例外運用を残しています。コードで確定した通常操作の条件まで保留にする必要はありません。権限の選択名はVB定義で確定していますが、実マスタの分類名・機能との対応や管理画面の正式項目名は実登録の確認が必要です。

第3版でも全52ケースのExcel／MD一致、単体参照、集計・結果欄、描画、srcと65・66の不変を確認。実ケースの実行は未実施です。
