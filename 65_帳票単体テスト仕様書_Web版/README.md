## 変更理由・使い方

VBの保存ダイアログやExcel自動起動をWebの必須動作から外し、ブラウザで取得後に手動で開く手順へ変更。支払帳票のZIP取得、xls／xlsx形式、契約時間別の明細、シート順、続紙境界、金額の丸め、通知後の中止を整理しました。

共通準備→帳票別ケース→不具合F01〜F04→未確定Q01〜Q06の順に確認してください。F01〜F03は静的に確認したコード上の不具合で、再現したら不合格です。F04の画面ソートと出力順は実機確認が残る候補です。Qに関係するケースは、基準を確定するまで合格にしないでください。

アプリへの上書き・反映は不要です。最新src、VB資料、元MDは変更していません。全ての帳票ケースを実行した結果ではなく、実施前のレビュー版です。
