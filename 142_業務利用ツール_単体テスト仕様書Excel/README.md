# MCM業務利用ツール 単体テスト仕様書（Excel）

使うファイルは **MCM業務利用ツール_単体テスト仕様書_20261103.xlsx** の1冊です。141のMDを基に、全16ツール・76ケースを収録しました。

## 使い方

1. 「単体テスト目次」で対象ツール名をクリックすると、そのシートへ移動します。
2. 「試験準備」「仕様書課題一覧」を確認し、使用する版・接続先・既存入力値・期待値を準備します。TL30～32は「実施前確認票」「確認観点対応」も使います。
3. 各ツールシートの前提条件・操作内容・期待結果・期待メッセージの順で実施します。
4. H列に初回結果、I～K列に実施情報・不具合内容を記入します。再テストはL～N列へ記入します。日付はExcelの日付として入力します。
5. O列の最終判定と目次の集計は自動更新します。未確認の分岐や実施できない理由はP列にも記録します。

## 構成・扱い

- 目次・課題一覧・準備関連3シート・ツール別16シートの計21シート。
- 既存の単体仕様書に合わせた16列構成。長文は省略せず、同じケースのセルを縦方向に結合して全文を表示しています。ケース数は表示行数ではなく項番で数えます。
- 結果の選択肢は「未実施／OK／NG／保留／対象外」。再テスト結果があれば優先します。初回結果が空欄の場合は未実施です。
- 未実装・準備待ちは対象外やOKに自動変換しません。TL30の6件は実装待ち、TL11-002は未作成のため76件に含めていません。
- 元MDは[141](../141_業務利用ツール単体仕様書_比較範囲と契約更新補足/README.md)です。本文は変更していません。141の「Excel化未実施」は、141作成時点の記録です。
