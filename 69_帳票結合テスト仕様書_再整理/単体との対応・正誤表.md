# 単体との対応・正誤表

対象単体：[66のMD](../66_帳票単体テスト仕様書_Excel版/MCM帳票_単体テスト仕様書_Web版.md)（65と同一、第13版・284ケース）。元のMD・Excelは変更していません。本表を単体の実施・結合の照合時に適用します。誤記に合わせて結合の正しい期待を変更しないでください。根拠の詳細は[68のVB差分](../68_帳票仕様書_VB再照合差分/VBとの不整合差分.md)にあります。

## 期待・前提の訂正

| 対象単体 | 適用する期待・前提 | 結合対応 |
| --- | --- | --- |
| 2001P-3、4、44、および末尾のシート順の説明 | VBの役割順は見積総括表→保守見積総括表（原価）→保守見積書→保守仕様明細目録→見積原価表→ハードウェア保守明細→ソフトウェア保守費明細。5番目は原価、6番目はハード。追加ブランド・期間の3〜7番目の組も同じ順。正式シート名・印刷構成は原紙確認が必要。Webの定数だけ入れ替えて合格とはしない。 | INT05-002・003 |
| 3001P-16、3005P-12 | 支払対象を満たす取引先契約の関連ユーザー契約で注記を確認。TSUKIがユーザー解約日の前なら「* 」なし、同日・後ならあり。NULLなら通常月はなし。取引先解約日より後のTSUKIは抽出対象外で注記確認に使わない。月途中の解約と同月月初のTSUKIは同月でも注記なし。 | INT06-004 |
| 1003P-5、同ケースから1003P-13への説明 | 解約日未入力の更新区分では、旧契約欄の金額・支払回数は直前有効期間、契約書番号は契約NOから取得。解約日欄は空欄。旧期間終了日を代わりに印字しない。解約日は解約区分1003P-6・13で別確認。 | INT03-002 |
| 3004P-28・29 | 金額4列は担当者マスタの取引先契約関連（分類3）が参照／作成なら表示、なしなら非表示。独立した金額表示設定は用意しない。実マスタの表示名称はQ06で確認。 | INT09-002 |
| 1003P-6 | 編集可能な契約の上段・契約共通の解約日を入力し、対象期間を選択して契約発行。期間タブ自身に解約日が設定されるという前提にしない。既に状態が解約の通常発行禁止とは分ける。 | INT03-003 |
| 1002P-15（単体は訂正不要） | MCM1003Uの実効権限が参照なら依頼一覧出力は非活性、帳票取得不可。単体の期待を保持し、第5版結合C10・INT09-001・環境確認手順をこれに統一。 | INT09-001 |
