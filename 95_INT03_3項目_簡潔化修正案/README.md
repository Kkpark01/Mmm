# INT03 3項目の簡潔化修正案

2026-10-16。[本文](INT03_01_02_05_修正案.md)。INT03-01（参照）・02（契約作成）・05（過去月支払による破棄拒否）の確認用修正案を作成した。02～04・INT05と同じ8項目の構造を維持している。

## 変更内容

- 01は見積1件の番号・時間・取引先・サポートIDと元画面保持へ絞った。全期間・機器・価格・DB前後比較を省く。前回見積との取り違えは09の作成時に残す案で、09の修正本文は今回未作成。
- 01の別タブは共通仕様2.1の期待。受領Webの同一タブ・キー受渡しの差異候補は備考に記載し、存在しない「戻る」を操作させない。
- 02は見積・機器を各1件へ絞り、入力値・ウィザード・登録・再検索を残した。DBは今回の契約と元見積・採用データの関連に限定。VB新規登録の確認2回と、完了通知がないことを維持した。
- 05は過去月の明細を持つ契約1件の拒否・状態維持へ絞り、支払出力と他画面での重複確認を省いた。

## 反映方法

現時点では本文の確認用。了承後に、94のExcelのINT03該当行へC～G・P列を反映する。項番・分類・実績欄・他シートは変更しない。今回Excel・既存MD・アプリsrcは変更していない。
