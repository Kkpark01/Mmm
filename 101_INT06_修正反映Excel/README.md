# INT06 修正反映Excel

2026-10-17。[100の了承済み本文](../100_INT06_12項目_簡潔化修正案/INT06_支払い連携_簡潔化修正案.md)を98のExcelへ反映した統合版。

ファイル：`MCM契・解約機能_結合テスト仕様書(261009版)_INT02・INT03・INT05・INT06修正版.xlsx`

## 反映内容・使用方法

このExcelをINT02・INT03・INT05・INT06反映済み版として使用する。元Excelや98へ上書きする必要はない。

- INT06全12項番のC～G列・P列、10～21行の計72セルへ本文を反映。01～05・07～13の項番・分類を維持し、統合済み欠番06は追加していない。
- 08・12・13は対象外。前提・備考に理由と確認しない範囲を記載し、H16・H20・H21へ「対象外」を設定した。実機で作成エラーを確認済みという意味ではない。
- INT06の実施予定9件・対象外3件を最終判定・件数・目次へ反映。既存数式は維持し、対象外登録により変わる計算結果を更新した。実施対象9件は「未実施」のまま。
- 11は正常出力→0件の年月へ入力変更→エラー確認の4手順。不要な契約編集は含めない。
- 操作手順・期待メッセージの末尾を読みやすくするため、INT06のE列幅を33.25から125、G列幅を14.625から80へ調整。他の列幅・文字サイズ・フォント・行高は維持。

## 検証

[検証結果](検証結果.json)を参照。

- Artifact Toolで編集した72セルと最終ファイルの値が全件一致。
- 元Excelと同じ48パーツ構成・順序を維持。INT06・目次以外の46パーツはバイト一致し、INT02・INT03・INT05、画像8点、既存スタイル・入力規則・印刷設定等を維持。
- 共有数式を含む全数式・計算チェーンを維持。本文・対象外区分・関連集計結果・対象2列の幅以外は変更していない。
- INT06の全12項番・実施予定9件・対象外3件と、全体の実施予定186件・対象外28件を独立照合。
- ZIPのCRC検査合格。最終保存ファイルを再読込し、対象12行・備考・集計を描画して折返しと本文末尾を確認。

元Excel・98・100の本文・アプリsrcは変更していない。
