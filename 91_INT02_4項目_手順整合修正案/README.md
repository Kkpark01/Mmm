## 試験範囲と準備担当者への引継ぎ

- 08は対象期間に承認済み資料を置かず、PDF1件を用意します。差戻し後の備考修正と同じ資料による再申請が成立する入力条件を準備担当が確認します。過去資料の詳細保護は14へ分担します。
- 12の通常手順は従来12-Aだけです。正常資料と失敗資料を一緒に処理する従来12-Cは、先行資料の復元範囲を決めるQ15の技術確認へ分離し、未確認のまま残します。今回の修正をもって従来12-Cまで実施済み・合格とは扱いません。
- 12の失敗資料は、準備担当が試験専用の正常なxlsx原紙を複製し、対象シートの図形 `stp_circle` だけを削除して作成します。対象シートは「契約手続依頼書①」で始まる名前とし、他の図形・ファイル形式・所属・権限・保存先は正常に保ちます。削除した図形名・対象シート名・処理前の押印欄を記録して引き渡し、一般実施者には加工させません。VBはこの枠図形を参照し、Webも必須図形として検査します。
- 12は保存失敗でFalseが返る条件とは異なります。VBの図形参照例外は、`CPButton.OnClick` の例外時ロールバック経路へ進みます。固定の図形不足メッセージIDは確認できず、共通例外処理は未分類の例外を再throwします。Webの「添付帳票に捺印用の図形がありません。帳票を確認してください。」はWebの業務案内であり、VBと同一文言・表示形式とは扱いません。図形不足で処理が進まないこととDBの状態維持をVB根拠の期待とします。VB実機でのエラー表示・Excel終了挙動は未確認です。
- 15の上限設定と試験契約4件の金額は、準備担当が作成済みの状態で引き渡します。上限設定後のB・Cの再ログインを含めます。本文の100,000円／200,000円を変更する場合は、準備値・手順・期待結果を一緒に変更し、「上限ちょうど」と「1円超過」を維持します。
- 28は1契約・1期間・PDF1件を使用します。これにより、現行一覧の「開始日」が契約内の最古の開始日を表示する仕様でも、照合する開始日が一意になります。承認中からの差戻しは今回の28の実施範囲に含めません。1011Uの08の結果を3001U経路の承認中差戻しの実績へ流用しません。
- DB確認は控えた対象キーの読取だけです。分担先の項番は確認先を示し、実施済み・合格を意味しません。
