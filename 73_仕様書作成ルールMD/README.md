## 別のAIへ追加で渡すもの

- 対象のVBソース、最新Webソース、関連する設計・共通仕様・DB定義・メッセージ定義。
- 構成・書式の基準となるExcelの実物。
- 既存の単体・結合テスト仕様書。実施結果がある場合は版と実績・証跡も明示。
- 対象画面一覧と今回の作業範囲。

これらのソースやExcelはこのZIPには含めていません。作業に使う最新版を別途渡してください。

## 依頼文の例

```text
添付の作成ルールMD6件と根拠資料を参照し、指定した対象画面のWeb版結合テスト仕様書を作成・修正してください。

期待動作はVBと承認済み仕様を根拠にし、操作手順はWeb版に合わせてください。VBの既知不具合や移行差異を機械的に再現せず、期待が変わる不明点は根拠とともに要確認にしてください。

既存の単体・帳票テストと重複する判定は分担先を記録し、結合では画面間・DB・後続処理・権限・排他・セッション等への追加判定を残してください。未実施・対象外を確認済みや合格として扱わないでください。

最終成果物は1つのExcelとし、添付の基準Excelの構成・列・書式・集計・入力規則を維持してください。MD中の古いシート数やセル配置より、基準Excelの実物と今回の指示を優先してください。細かなディレクトリやツール指定は作業環境に合わせて構いません。

各ケースは前提→操作→期待結果の順に実行可能な内容とし、出力前に出力結果を照合するような順序の矛盾をなくしてください。

根拠のない内容は確定せず要確認とし、ケースの重複・参照・操作順・集計・Excelの表示を検証してください。確認済みの範囲と未確認事項を明記してください。別AIへの委任や有料サービスの利用は、別途明示的な依頼がある場合のみ行ってください。

対象画面：［ここに記入］
今回の依頼範囲：［作成／修正／レビュー等を記入］
```

## 注意・検証

このフォルダへのコピーでルールが自動適用されるわけではありません。別AIにはREADMEを含めて読むよう依頼してください。MDは元の参考資料であり、今回のユーザー指示・承認済み仕様・基準Excelの実物を優先します。

MD6件は原本とSHA-256一致を確認。内容の最新化や新しい仕様書の作成は今回行っていません。ZIP内容と同梱ファイルへのリンクを確認しました。元の参照資料とアプリsrcは変更していません。
