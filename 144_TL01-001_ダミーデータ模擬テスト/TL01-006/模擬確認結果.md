# TL01-006 元版と改修版の模擬比較結果

**同じダミーデータによる帳票のセル値比較は一致しました。** 受領原版と131改修版でそれぞれ帳票を生成し、各36項目の確認に合格しました。

| 確認内容 | 結果 |
|---|---|
| 出力シート | 両方とも「保守見積依頼」1枚 |
| 比較範囲 | 両版の使用範囲を合わせたA1:BJ12 |
| セル値 | 744セルを比較し、差異0件 |
| 空欄・数値・文字列 | 区別して比較。日付は元の数値として比較 |
| 0件の誤合格防止 | どちらも明細3件・構成見出し2件が存在 |

入力はTL01-002と同じ4行のダミーデータです。元版はOracle取得・CSV読込み、改修版はSQL Server取得を、それぞれ同じダミーデータを渡す処理に置き換えました。元版側の模擬取込には、元の表示倍率・文字サイズの設定を再現しています。帳票加工・転記・保存はそれぞれの対象版の処理を使用しました。

**SQL・DBの抽出結果自体、両DBの同時点性、実際のボタン・ダイアログ操作は未確認です。** この比較は実DBでのTL01-006全体を合格にするものではありません。罫線・列幅・画像・印刷設定は本ケースの比較対象に含めていません。プレビューは生成Excelの画像化で、実操作のスクショではありません。
