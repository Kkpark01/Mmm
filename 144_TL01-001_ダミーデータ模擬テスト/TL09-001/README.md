# TL09-001 TSSA更新用CSVの模擬テスト

**部分確認：010・020・040は9項目が一致し、030も試験用の代替関数を使った出力で6項目が一致しました。実際のExcel関数ではエラーとなるため、ケース全体は未判定です。**

136版のCSV出力VBAを、架空の行を用意した試験用Excelで実行しました。010・020は14列、040は7列で、それぞれ見出しと1行のデータを出力しました。入力データの取得や対応表による加工は実行していません。

030の出力途中に、Excelの `WorksheetFunction.TextJoin` で実行時エラー1004が発生しました。同じExcelで文字列2つを結合する単独試験でも同じエラーだったため、このPCのExcelでは当該関数を利用できない状態と考えられます。別のExcel環境での動作は未確認です。実際の `TEXTJOIN` を使用した030の生成は未確認です。

追加の模擬試験では、利用できない `TEXTJOIN` の呼出だけを試験専用の連結関数へ置き換え、030の残りの処理を実行しました。数量2・数量1の入力が3行へ展開され、19列と `00000001`〜`00000003` の連番、出力値の6項目が一致しました。**これは代替関数を使った結果であり、実際のExcelの `TEXTJOIN` が動くことは確認できていません。**
