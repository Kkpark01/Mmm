# TL01 テスト結果Excel（試作）

[TL01のテスト結果Excel](TL01_取引先見積依頼書_テスト結果.xlsx)は、単体テスト仕様書のTL01-001・002・004・006を1ケース1シートにまとめた試作です。

各シートに、現在の模擬判定、未確認範囲、画像、仕様書本文を収録しています。画像は模擬出力のプレビューで、実操作中のスクリーンショットではありません。正式な実DB・実画面での試験は未実施です。仕様書や判定は作成時点の写しです。

4ケースの本文とMDの照合、埋込画像7点、シートの表示を確認しました。実施結果を管理する正式な仕様書Excel（142）には反映していません。
