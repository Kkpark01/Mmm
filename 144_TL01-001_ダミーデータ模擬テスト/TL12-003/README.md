**部分確認：取得結果を0件に置き換えた場合、前回結果が消えて見出しだけが表示されることを確認しました。**

## 空欄になる可能性の追加確認

131版の検索SQL全文をローカルSQL Server上の架空の一時表で実行したところ、サポートIDをNULLにした行がID空欄のまま検索結果に含まれました。検索SQLはこの条件を除外していません。前述の消去漏れは、その行が検索結果の末尾にある場合に起こり得ます。

検証DBの実際の列定義、該当データの存在、会社編集版でも同様かは未確認です。

## 受領済みDB定義との照合

受領済みのSQL Server向けテーブル定義では、MCM_TM_MITSUMORI の SUPPORT_ID は NULL を許可する定義でした（[定義資料](../../../参照用/引継資料_20260915/参考資料/MCM_CreateTables_SQLServer.sql) の 534 行目）。これは過去の参考資料で、稼働中の検証DBの現在の定義や該当データの存在を確認したものではありません。
