# TL10-001 サポートID検索

**部分確認：条件を引き渡すVBAと、検索SQLの条件部分をそれぞれ模擬確認しました。**

131版VBAに、サポートIDと納入先コードの両方・それぞれ片方・両方空欄を入力し、3本の取得処理に渡す値、31列の指定、見出しの有無が期待どおりでした。IDは7桁へ整形されます。

別途、SQLの1本目から検索条件部分を抜き出し、ローカルSQL Serverの一時表に入れた架空の5行で確認しました。両方入力ならどちらかが一致する2行、片方ならそれぞれ1行、空欄なら0行となり、先頭99のIDと納入区分がある行も除外されました。

実SQLの結合部分・残り2本・画面操作・実DB・会社編集版は未確認です。ExcelとSQLは別々に実行しており、ケース全体は未判定です。一時表は接続終了時に消え、業務DBへの変更はしていません。画像はありません。
