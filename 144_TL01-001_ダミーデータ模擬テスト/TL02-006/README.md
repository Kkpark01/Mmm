# TL02-006 元版と改修版の一覧加工の模擬比較

**一覧加工の模擬比較では、B1:N4の52セルが一致しました。** 見出し13セルとデータ3行×13セルです。両方とも、支払回数・支払月・金額・製番・照合キーが一致しました。

元版のPayList後半（表示・加工・並べ替え）と、131版の同じ処理をそれぞれ動かしています。ただしデータ取得は両方ともダミーです。

- 元版：Oracleの支払金額関数を実行できないため、手計算の期待値8,337円・8,333円・100,000円を入力。
- 改修版：131版のMcmCalculatePaymentで同じ金額を計算。
- **元版のOracle関数そのもの、両DBの抽出結果・同時点性は未確認。** この結果をTL02-006全体の正式合格にはできません。
