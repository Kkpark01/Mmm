**解約・撤去の追加模擬確認**：架空の4行を入力し、当月1日より前の解約日と撤去日があり、取引先契約が「契約」以外の1行だけが削除されました。過去解約でも取引先契約が「契約」の行は残り、HW・SW製番がクリアされました。解約日なしの撤去行と通常行も残ることを含め7項目が一致しました。実際の年月境界や他の組み合わせをすべて網羅したものではありません。

元の131版では店舗リストのID列が文字列書式であることを確認し、試験用の列にも同じ書式を設定しました。最初の試験用シートでは書式を再現しておらず、先頭0が消えたため、この書式を再現して再試験しています。追加で再適用から一覧保存までを同じ入力で一連実行しています。実DB・実画面・会社編集版は未確認です。
