# TL31-005 開始確認の取消

**部分確認：試験用コピーの実画面で開始をキャンセルし、処理を開始せず画面に戻りました。**

ローカルの試験DBで架空の付替元・付替先を表示した後、「開始」→「キャンセル」を選択。「開始をキャンセルしました」が表示され、架空プラント2件のIDと納入先IDは変わらず、更新ログも作成されませんでした。試験DBは削除済みです。

仕様書にある6表のうち、架空DBに用意して確認したのはプラント・納入先の2表です。残りの表や会社編集版、実DBは未確認です。
