## 条件に使う時間帯の比較

架空データの同じ見積で、基本見積の時間帯を8、基本ブランドの時間帯を24とし、8時間で検索しました。SQLの曖昧な条件だけを試験用にそれぞれの表名付きへ置き換えると、基本見積を条件にした場合は対象が含まれ、基本ブランドを条件にした場合は含まれませんでした。

このため、エラー解消時は列名に表名を付けるだけでなく、どちらの値を検索条件として使うかを確認する必要があります。現在の131版SQLの表示列は基本見積側で、仕様書の用語表も表示元を基本見積としています。ただし、この試験は正式な検索仕様や実データで両値が異なることを確定するものではありません。配布ファイルは変更していません。
