# TL08-002 複数契約から単一契約への再検索

**部分確認：架空の取得結果を使い、再検索時の条件・結果の消去を確認しました。**

131版の取得後処理を隔離Excelで実行し、契約A・B指定時に架空データ3行、Aのみ指定時に1行を返すよう取得部分を置き換えました。初回の重複除去後にA・Bが表示され、Bに異なるメーカーを設定すると警告を記録しました。Aだけの再検索ではBの条件・結果が消え、メーカー警告は記録されず、両回の完了処理も確認できました。計12項目が一致しました。

実際にDBが指定された契約の機器だけを返すかは未確認です。画面ボタン・実ダイアログ・会社編集版も未確認で、メッセージは表示せず記録に置換しています。スクリーンショットはありません。
