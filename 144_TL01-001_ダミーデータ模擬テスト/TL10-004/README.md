# TL10-004 一次納入日の指摘

**模擬確認：一次納入日が空欄の場合の印・色・文字の装飾と警告文など10項目が一致しました。**

131版の日付確認VBAを、架空の4行（空欄、撤去済み、有効な日付、日付以外）を用意した試験用Excelで実行。空欄と不正日付の行は×、撤去済みと有効日付の行は指摘なしとなりました。空欄セルの灰色背景・赤文字・太字・斜体、見出しマーク、警告文も確認しました。

実DBによる対象抽出、他の照合処理、ボタン操作、実際のダイアログ、会社編集版は未確認です。保存ファイルは独立した処理の観察用で、業務の出力帳票ではありません。画像はExcelのプレビューです。
