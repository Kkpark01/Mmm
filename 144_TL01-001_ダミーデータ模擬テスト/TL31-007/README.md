# TL31-007 接続先未設定時の起動

**模擬合格：試験用コピーでServerを空欄にして起動すると、仕様書どおりのエラーが表示され、OK後にプロセスが終了しました。**

133版のEXEを専用フォルダーにコピーし、設定はServer空欄・架空のDatabase名・Windows認証としました。エラーのタイトル・全文を画面のアクセシビリティ情報で確認し、OK押下後に試験用プロセスが終了したことと、更新ログが新規作成されていないことを確認しました。DBへの接続・更新は行っていません。元のEXEとコピーのハッシュは一致しています。

スクリーンショットは取得画像に別ウィンドウが写ったため、証拠として保存していません。会社編集版・正常なDBへの接続は未確認です。
