# TL06-005 支払データの模擬テスト

**要確認：131版では、契約期間の重複がない模擬データで、支払一覧の出力途中にExcelエラー1004が発生し、ファイルが保存されませんでした。**

架空の取得済みデータ、原紙コピーと模擬契約期間を使い、支払いデータ抽出を一連実行しました。準備状態の確認、期間データの取込み、完了通知だけを試験用に差し替えています。実DB・実ボタン・実ダイアログ・会社編集版は未確認です。

## 原因の切り分け

- 期間データが重複しない場合、重複を探すフィルターが残ったまま後続の取引先情報の当て込みへ進み、列のコピー時に「この操作は複数の選択範囲に対しては機能しません。」が発生しました。
- 同じ契約に期間データが重複する模擬条件では、フィルターが解除され、一覧が保存されました。
- 試験用コピーだけで、重複がない場合にもフィルターを解除する仮変更を加えると、同じデータで保存できました。**これは原因を確かめる試験であり、配布用マクロの修正ではありません。**

## 保存できた場合の確認

期間重複の場合と試験用仮変更の場合について、対象契約・先頭0付きID・最新の取引先情報・製番・期間・月額10,000円など各16項目が一致しました。実際のDBから取得した期間データ、列の型・書式、会社編集版への影響は未確認です。Excelの支払一覧原紙に元からある値は今回の出力結果として扱っていません。

## 使用した原紙の確認

試験で使用した原紙のSHA-256は、131版の「08_メーカ契約機器リスト作成」に同梱された「【テンプレート】BCP支払一覧.xlsx」と一致しています。この原紙には処理が参照する「取込リスト」「製番リスト」「取引先契約期間データ」の3シートがあります。したがって、この試験は02用の別原紙を取り違えて実行したものではありません。ただし、会社編集版で使用している原紙の一致は未確認です。

## 現行版との比較

受領した現行版 `メーカ契約機器リスト作成ver2.4.xlsm` を読み取り専用で開き、支払一覧のVBAを確認しました。現行版にも、期間重複の抽出フィルターを設定し、対象がない場合は解除処理より前で処理を抜ける構造があります（抽出したVBAの262～267行）。

131版で確認したフィルター残りの原因と同じ構造は現行版にもあります。ただし、現行版を同じ条件で実行したわけではないため、現行版でも実際に同じエラーになるとは断定できません。今回の確認はソース比較であり、元ブックは変更していません。
