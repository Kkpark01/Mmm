# TL32-010 原紙に店舗がない場合

**部分確認：架空店舗が原紙にない場合、出力処理がエラーで止まり、既存ファイルを維持しました。**

137版の出力処理を直接呼び出し、架空店舗・試験用原紙・同名の既存ファイルを使いました。「原紙D列の一致が0件」「帳票は保存しません」というエラーが返り、原紙と既存ファイルは変わらず、作業用ファイルも残りませんでした。既存ファイルは内容保護を確認するための模擬ファイルで、実際の帳票ではありません。

DB取得、上書き確認ダイアログ、画面のエラー表示・ボタン復帰、ログは未確認です。スクリーンショットはありません。

- [確認結果](確認結果.json)

## 実画面での追加確認

保存確認を「いいえ」で取り消した後、試験用の既存帳票を別フォルダに退避して再実行しました。架空データのローカルDBから取得後、原紙に店舗がない旨のエラーが表示され、OK後はボタンが有効に戻りました。原紙は不変、出力と作業用ファイルはなく、ログに異常があり保存完了はありません。試験DBは削除済みです。

この実画面試験ではエラー発生時に同名帳票を置いていないため、仕様書どおりの「同名帳票がある状態で上書きを承諾した後」の一連操作は未確認です。同名ファイルを保持する出力処理の直接試験は上記のとおり実施済みです。
