# TL06（メーカ契約機器リスト作成） 用語表・根拠

2026-11-02。手元の131の「08_メーカ契約機器リスト作成」を読み取り専用で調査した。利用者が別環境で編集した実物とは未照合。本文は作成案であり、実機試験の合格記録ではない。

## 1. 対象と版

- 実行ブック：メーカ契約機器リスト作成ver2.4.xlsm。
- フォルダ番号08と管理表番号TL06は別の番号。
- 131は129の取得・加工改善と、実行ブックと同じフォルダへ保存する変更を含む。
- 元ファイルのSHA-256は検証記録のsource.jsonに保存。VBA抽出、内蔵SQL、図形の割当、Excelでの読み取り専用確認を実施。ファイル変更・業務マクロ実行・DB接続は行っていない。
- フォルダ名にOKは付けない。追加編集された版に着手する際は、下記の割当・入力位置・出力前チェックを照合する。

## 3. 入力と出力

| 項目 | 場所・内容 |
|---|---|
| 支払対象年 | 操作シートN4。保存済み値をそのまま使わず、準備した年を入れる |
| 支払対象月 | 操作シートP4。1～12のうち、準備した月を入れる |
| 取込データ | 1行目が見出し、2行目からデータ |
| 店舗リスト | A列＝サポートID、B列＝担当店舗 |
| 機器分類表 | A列＝機器ID、E列＝分類フラグ。個別機器分類表による上書きがある |
| 店舗別一覧の原紙 | _【テンプレート】店舗別　『機器一覧』.xlsx。シートALL |
| 店舗別一覧の出力 | 店舗別　『機器一覧』_yyyymmdd_hhnnss.xlsx。実行ブックと同じフォルダ |
| BCP原紙 | 【テンプレート】BCP支払一覧.xlsx |
| BCP出力 | 【BCP対策】支払一覧_{年}年{月}月_{作成日時}.xlsx。実行ブックと同じフォルダ |
| BCP内のシート | 支払一覧、取込リスト、製番リスト、取引先契約期間データ |

実装の日時書式は、店舗別一覧がyyyymmdd_hhnnss、BCPがyyyymmdd_hhmm。BCPの分部分もVBA Formatのmmで現在時刻から生成される。本文では具体的な作成日時を実施時に記録し、固定しない。

## 4. 取込データの確認列

| 列 | 表示見出し | 確認内容 |
|---|---|---|
| B | 機器管理ID | 個体管理IDと機器明細IDを「 / 」で連結した取得元の値。比較表には取得元と同じ表記を記入する |
| C | 店舗 | 取得SQLのこの位置はプラントID。取得直後に担当店舗が自動で入るとは期待しない。担当店舗再適用後は店舗リストの値になる |
| D | サポートID | 文字列の識別値。先頭0がある場合も維持 |
| E・G・J | 納入先コード・納入先名・システム名 | 機器の照合に使用 |
| R | 取引先契約状態 | 契約・途中解約等の取得値 |
| T・U・V・W | 機器品名・機器型式・シリアル番号・数量 | 機器の照合に使用 |
| AR～AU | 開始日・終了日・ハードウェア製番・ソフトウェア製番 | 契約製番の当て込み |
| AF・AV | 撤去日・解約日（ユーザー） | 店舗別一覧での削除対象の準備に使用 |
| CT・CU | 合計価格・支払回数 | BCPの対象と金額計算 |
| CV～DG | 1月～12月 | BCPの対象月に○が付いているか |
| DH | 取引先契約ID | BCPの契約単位の照合 |

## 5. 取得の経路

- Get_MCM → adoget_mcm("ALL") → McmEndData.FetchMain。
- 未契約、解約（途中解約）、契約の3種類をこの順に取得。製番・取引先契約期間もブック内へ保持する。
- 主データの内蔵SQLはexternal_03・external_01・external_02。未契約は一時テーブルを使う改善版。製番はexternal_04、契約期間はexternal_05。
- 同じ機器管理IDは後ろの行を残して1行とする。取込データは納入先コード、サポートID、システム名の順に並べる。
- 取得直後の処理に担当店舗再適用・機器分類再適用の呼出はない。これらを自動で完了するというTL05の期待を流用しない。
- 取得・加工成功時だけ取得情報を完了にする。List_Create・Output_PayListにはRequireReadyの呼出が残る。
- 完了表示の件数は店舗リストA列の最終行とB列の最終行の差。今回DBへ追加登録した件数ではない。表現の妥当性は今回の仕様書作成で変更しない。

## 6. 出力の経路と確認先

店舗別一覧はOutput_List.List_Create・Edit_cont_status。原紙への転記後に判定・期間列を追加するため、機器管理IDは出力のAY列（14行目見出し、15行目からデータ）。元の取込データB列と同じ列位置ではない。

当月1日より前のユーザー解約日がある行は製番等が空になる。さらに撤去日も当月1日より前で、取引先契約状態が契約でない行を削除する。004の準備は、この条件と出力件数を控える。

BCPは■Payout.Output_PayList。対象月の○、合計価格が0以外、取引先契約状態が契約の行を対象とする。取引先契約IDで重複を除き、取込リストへ契約・金額を、製番リストへ製番を、取引先契約期間データへ取得済み期間を渡す。

| BCPの確認先 | 列 |
|---|---|
| 取込リスト | A＝契約ID、B＝サポートID、E＝取引先CD、F＝取引先名、G＝契約No、I＝合計価格、J＝支払回数、K・L＝製番開始終了、M＝HW製番、O・P＝契約期間開始終了、R＝支払金額 |
| 製番リスト | A＝契約ID、H・I＝製番開始終了、J＝HW製番 |

**注意：支払一覧シートへIDを転記したり、行の式を展開したりする呼出は、この出力マクロ内にない。** 原紙には手作業向けの指示と保存済みの値がある。今回自動更新されたデータの確認先は取込リスト等とし、支払一覧の残存値を期待値として使用しない。手作業の仕上げまで試験するかは元担当AIへ引き継ぐ。
