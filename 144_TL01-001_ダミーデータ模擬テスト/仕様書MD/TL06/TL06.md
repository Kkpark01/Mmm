# TL06（メーカ契約機器リスト作成） 単体テスト仕様書・本文案

準備方針：[共通方針と準備記録](../00_試験準備の共通方針.md)。このケースで使う既存入力値・期待件数・対象版を準備担当者が記入する。DBの試験データ新規登録は行わない。

2026-11-02。対象は131の「08_メーカ契約機器リスト作成／メーカ契約機器リスト作成ver2.4.xlsm」。会社で編集した版とは未照合。以下はコード・原紙・ボタン割当を確認して作成した案であり、試験済みの記録ではない。

凡例：
- 実施者：試験を行う人。Excelでツールを操作し、表示と出力を確認する。
- 準備担当者：検証DBの既存データを選び、試験データ表と必要な試験用コピーを実施者へ渡す人。DBへ新規登録はしない。
- 試験データ表：準備担当者が、取得元を確認して期待値を記入する表。出力後の結果から逆算して埋めない。表が空、または条件に合うデータがない場合は「準備未完」とする。
- 各ケースの「前提条件」「操作内容」「期待結果」は、そのケースだけを読んで実施できるように記載する。004・005は取得成功済みの試験専用コピーを使う。
- このツールにはメッセージIDがないため、期待メッセージの「メッセージID」は「－」とする。
- 実施区分：通常／要確認／開発者テスト／実施不可／除外候補。006は現行版と同じ時点のデータが必要なため「要確認」とする。
- ボタン名は装飾文字を除く表示名で記載する。入力セル・処理条件は[用語表](用語表.md)、保留範囲は[骨子](骨子.md)を参照する。

項番の欠番：

| 項番 | 理由 |
|---|---|
| 002・003 | 対象ブックに契約中リスト抽出・指定リスト抽出のボタンがないため作らない。 |
| 007 | 接続エラー等の確認範囲を検討中。TL06固有の取得中断時の扱いも含めて確認する。 |

## TL06-001

### 項番
TL06-001

### テスト項目
TL06（メーカ契約機器リスト作成）：「データリスト作成」で全件を取得でき、機器管理IDの重複がなく、選んだ既存機器の情報・製番が取込データに反映されること。

### 前提条件
```
実施区分＝通常（試験データ表の準備後）。

【この試験で確認すること】
「データリスト作成」で全件を取得し、機器管理IDが重複せず、選んだ既存機器の情報と製番が「取込データ」に反映されること。

【実施する人】
・実施者（試験を行う人）。
・準備担当者（検証DBの既存機器を選び、試験データ表を用意する人）。

【実施者に必要なもの】
・Excelでマクロを実行できるPCと、08_メーカ契約機器リスト作成のフォルダー一式の試験用コピー。
・Mcm移行部品内の設定と必要な接続ドライバー・認証が準備され、接続先が検証DBであることを準備担当者が確認済み。認証情報はエビデンスに写さない。
・取得中に他の作業で元データを変更しない時間帯を確保していること。

【準備担当者が用意するデータ】
このブックの全件取得SQLの対象となる既存機器を1～3件選ぶ。契約／未契約／途中解約のうち用意できた区分を明記する。
少なくとも1件は製番が当て込まれる機器を選ぶ。先頭0のあるサポートIDがあれば、その機器も選ぶ。
値は取得元の検証DB・既存画面で取得開始前に確認する。製番が複数ある場合は、当て込み条件により採用される製番と期間を確認して書く。

試験データ表（機器ごとに1行。実施時は列を分けて記入してよい）：
| 機器管理ID（個体管理ID / 機器明細IDの表記） | 取得区分 | サポートID | 納入先コード・名 | システム名 | 取引先契約状態 | 品名・型式・シリアル番号・数量 | 製番開始日・終了日・HW製番・SW製番 |
| | | | | | | | |

完了通知の件数n＝店舗リストのA列最終行番号 − B列最終行番号：［記入］件。
確認日時：［記入］。nはサポートIDのDB登録件数ではない。

【開始時の状態】
Excelを起動していなくてよい。試験用コピーを使用し、取得中に元データを変更しない。
```

### 操作内容
```
1. 試験用の「メーカ契約機器リスト作成ver2.4.xlsm」を開き、マクロを有効にする。「操作シート」を選ぶ。
2. ②「データリスト作成」（C7付近）を押す。押下時刻を控え、完了通知が出るまで他のボタンを押さず待つ。
3. 完了通知の全文と表示時刻を控え、「OK」を押す。
4. 「取込データ」を選ぶ。B列を選択してCtrl＋Fを押し、試験データ表の機器管理IDを検索する。「セル内容が完全に同一であるものを検索する」を有効にし、「すべて検索」で一致件数と行番号を確認する。
5. 見つけた行のD・E・G・J・R・T～W・AR～AUを試験データ表と照合する。複数機器を選んだ場合は、機器ごとに4～5を行う。
6. B列のデータ範囲をコピーして新しい比較用ブックへ「値」で貼り付ける。貼付列を選んで「条件付き書式」→「セルの強調表示ルール」→「重複する値」を設定し、データ行に重複の強調表示がないことを確認する。見出しと空白行は対象に含めない。
7. 比較用ブックをエビデンス用に保存する。試験用ツールは保存せずに閉じる。

【入力値】
検索条件の入力はない。M12へのサポートID入力は行わない。
```

### 期待結果
```
【画面確認】
・手順3で「MCMデータ取得完了」の通知が表示され、nが試験データ表と一致する。start／endに今回の開始・終了日時が表示される。
・手順4で、選んだ各機器管理IDはB列に1件ずつ存在する。
・手順5でD＝サポートID、E＝納入先コード、G＝納入先名、J＝システム名、R＝取引先契約状態、T＝品名、U＝型式、V＝シリアル番号、W＝数量が準備値と一致する。
・AR＝製番開始日、AS＝製番終了日、AT＝HW製番、AU＝SW製番が準備値と一致する。先頭0を含む識別値は欠けない。
・手順6で機器管理IDの重複がない。
・担当店舗と機器分類の再適用はこの取得ボタンでは自動実行されないため、本ケースの取得完了条件に含めない。

【DB確認】
実施不要（DBを読む処理であり、更新処理はない。準備時の取得元確認は別）。
```

### 期待メッセージ
```
表示タイミング＝手順2の取得・加工完了時。
表示形式＝Excelメッセージボックス。
メッセージID＝－。
表示文言＝
MCMデータ取得完了

新規サポートIDの追加は　【n件】です。

start:　開始日時
end  :　終了日時
作業者操作＝件数と日時を記録し、「OK」を押す。
```

### 備考
取得時間は実測値を記録する。秒数による合否基準は未合意のため設けない。選択機器の列照合とB列の全件重複を確認するケースであり、全列・全行の値一致を保証するケースではない。

## TL06-004

### 項番
TL06-004

### テスト項目
TL06（メーカ契約機器リスト作成）：担当店舗・機器分類を再適用し、「終息リスト作成」で店舗別機器一覧を実行ブックと同じフォルダーに保存できること。

### 前提条件
```
実施区分＝通常（試験データ表の準備後）。

【この試験で確認すること】
担当店舗と機器分類を再適用し、店舗別機器一覧の保存先・転記内容・準備した行の出力結果を確認する。

【実施する人】
・実施者（試験を行う人）。
・準備担当者（既存機器を選び、取得成功済みの試験専用ブックと試験データ表を用意する人）。

【実施者に必要なもの】
・マクロを実行できるExcel。
・取得・加工を正常完了して保存した試験専用ブックと、同じフォルダーの「_【テンプレート】店舗別　『機器一覧』.xlsx」。原紙は閉じておく。
・フォルダーに書込権限があり、既存出力を上書きしないこと。

【準備担当者が用意するデータ】
正常に取得したブックのコピーを使う。取得済みの判定情報を手入力で偽装しない。
試験用コピー内の「取込データ」は、既存機器の1～3行だけを残してよい。見出し・列・他シートを削除しない。DBは変更しない。
各機器は「店舗リスト」A列にサポートID、B列に担当店舗があり、機器分類表または個別機器分類表で分類が決まるものを選ぶ。
少なくとも1行は削除対象外とする。下記の削除対象が存在しない場合、削除の分岐は本ケースでは未確認と記録する。

削除対象＝AV列の解約日（ユーザー）が実行月1日より前、AF列の撤去日も実行月1日より前、R列の取引先契約状態が「契約」以外、の全条件を満たす行。

試験データ表：
| 機器管理ID | サポートID | 担当店舗（店舗リストB列） | 再適用後の分類 | 納入先コード・名 | 品名・型式・数量 | Rの状態 | AF撤去日・AV解約日 | 出力に残る／削除される | 出力の製番・開始日・終了日 |
| | | | | | | | | | |

取込データ件数N＝［記入］。削除対象件数D＝［記入］。出力期待件数N−D＝［記入］。
実行月1日＝［年月日を記入］。月が変わった場合は準備値を見直す。
解約日が実行月1日より前の行は、出力の製番・開始日・終了日が空になる点も準備値へ反映する。

【開始時の状態】
Excelを起動していなくてよい。原紙は閉じ、準備済みの試験専用ブックを使用する。
```

### 操作内容
```
1. 準備済みの試験専用ブックを開き、「操作シート」を選ぶ。
2. ③の右「担当店舗再適用」（F11付近）を押し、「店舗再引き当て完了」の「OK」を押す。
3. ④の右「機器分類再適用」（H15付近）を押し、「機器分類再引き当て完了」の「OK」を押す。
4. 「取込データ」のB列で対象機器を検索し、同じ行のC列が担当店舗、A列が分類の準備値と一致することを確認する。
5. 「操作シート」に戻り、⑥「終息リスト作成」（C23付近）を押す。完了通知の「OK」を押す。
6. 実行ブックのあるフォルダーを開き、今回作成された「店舗別　『機器一覧』_作成日時.xlsx」を開く。ファイル名と保存先を控える。
7. 出力の「ALL」を選ぶ。14行目の見出し、15行目以降のデータを確認する。AY列の機器管理IDを完全一致で検索し、残る機器の行と、削除される機器が存在しないことを確認する。
8. 残る行のA列担当店舗・B列分類、D列サポートID、E列納入先コード、G列納入先名、T列品名、U列型式、W列数量、AR～AUの製番期間・製番を試験データ表と照合する。データ行数がN−D件であることを確認する。
9. 出力を閉じる。試験専用ツールは保存せずに閉じる。

【入力値】
検索条件の入力はない。実行月はPCの日付を使う。
```

### 期待結果
```
【画面確認】
・再適用の2つの完了通知が表示され、取込データA・C列が試験データ表と一致する。
・一覧作成後に「終息リスト書き出し完了」が表示される。

【ファイル確認】
・実行ブックと同じフォルダーに、今回の作成日時を含むxlsxが新しく保存される。別の「出力結果」フォルダーへ保存されない。
・ALLの14行目が見出し、15行目以降がデータ。機器管理IDはAY列に存在する。
・残る機器のIDと各列の値が準備値に一致し、削除対象の機器は存在しない。件数はN−D件。
・再適用後の分類が「-」の場合は出力では空白となる。取引先契約状態の「途中解約」は出力では「解約」となる。
・実行月1日より前のユーザー解約日を持つ行では、AR～AUの製番期間・製番が空になる。該当行を準備できなかった場合は、この分岐を未確認と記録する。

【DB確認】
実施不要（再適用は試験専用ブック内、出力はファイル生成。DB更新なし）。
```

### 期待メッセージ
```
表示タイミング＝手順2、手順3、手順5のそれぞれの処理完了時。
表示形式＝Excelメッセージボックス。
メッセージID＝いずれも－。
表示文言＝手順2「店舗再引き当て完了」、手順3「機器分類再引き当て完了」、手順5「終息リスト書き出し完了」。
作業者操作＝文言を確認し、それぞれ「OK」を押す。
```

### 備考
ブック内の試験データ行を絞る方法は出力経路の確認用であり、DB更新ではない。大量データの出力時間はこのケースの対象外。取得前の出力可否は会社編集版との照合待ちであり、このケースで確認済みとは扱わない。

## TL06-005

### 項番
TL06-005

### テスト項目
TL06（メーカ契約機器リスト作成）：支払対象年・月を指定し、「支払いデータ抽出」で対象契約・製番・契約期間・支払金額をBCP出力ブックへ転記できること。

### 前提条件
```
実施区分＝通常（該当する既存契約の確保後）。

【この試験で確認すること】
支払対象年・月を入力して「支払いデータ抽出」を押し、BCP出力ブックの対象契約・製番・契約期間・支払金額を確認する。

【実施する人】
・実施者（試験を行う人）。
・準備担当者（既存契約を選び、取得成功済みの試験専用ブックと試験データ表を用意する人）。

【実施者に必要なもの】
・マクロを実行できるExcel。
・取得・加工を正常完了して保存した試験専用ブックと、同じフォルダーの「【テンプレート】BCP支払一覧.xlsx」。原紙は閉じておく。
・フォルダーに書込権限があり、既存出力と名前が重ならないこと。

【準備担当者が用意するデータ】
検証DBの既存契約を1件選び、正常取得済みのコピーを用意する。「取込データ」はその契約の行だけに絞ってよい。製番・契約期間等の保持シートは削除しない。
・R列の取引先契約状態が「契約」、CT列の合計価格が0以外、CU列の支払回数が12。
・指定月の列（CV＝1月～DG＝12月）が「○」。
・採用される取引先契約期間が12か月で、指定月1日がその期間内。期間不足・更新確認の対象ではない。
・採用されるHW製番が1つに決まり、製番開始日≦指定月1日＜製番終了日。
・店舗リストA・B列にサポートIDと担当店舗がある。
同一契約に複数機器がある場合は、その行も残して契約ID単位の重複除去を確認する。1行しかない場合は重複除去の分岐は未確認と記録する。
該当する既存契約がなければ、勝手に金額・期間を編集せず「準備未完」とする。

試験データ表：
| 項目 | 準備値 |
| 対象年／月（N4／P4） | |
| 取引先契約ID（DH列） | |
| サポートID／納入先名／担当店舗 | |
| 採用される契約期間の取引先コード／取引先名／契約No | |
| 合計価格（CT列）／支払回数（CU列＝12） | |
| HW製番／製番開始日／製番終了日 | |
| 採用される取引先契約期間の開始日／終了日 | |
| 期待支払金額（合計価格÷12。端数を含む数値） | |
| 取込データに残した行数／対象機器管理ID | |

期待値は取得元と採用期間から確認する。古い期間の取引先名や原紙に残る値を使用しない。

【開始時の状態】
Excelを起動していなくてよい。原紙は閉じ、準備済みの試験専用ブックを使用する。
```

### 操作内容
```
1. 準備済みの試験専用ブックを開き、「操作シート」を選ぶ。
2. ③の右「担当店舗再適用」（F11付近）を押し、完了通知の「OK」を押す。
3. N4へ試験データ表の年、P4へ月を入力する。保存済みの年・月をそのまま使用しない。
4. 右上の「支払いデータ抽出」（M5付近）を押す。「支払いデータ抽出完了」が出たら「OK」を押す。
5. 実行ブックのあるフォルダーで、今回作成された「【BCP対策】支払一覧_{年}年{月}月_{作成日時}.xlsx」を開く。ファイル名と保存先を控える。
6. 出力の「取込リスト」A列で契約IDを完全一致で検索する。該当行のB～D、E～G、I・J、K～M、O・P・Rを試験データ表と照合する。金額はセルを選んで数式バーの数値も確認する。
7. 出力の「製番リスト」A列で同じ契約IDを検索し、H・I列の製番開始・終了日、J列のHW製番を照合する。「取引先契約期間データ」のA列で同じ契約IDを検索し、H・I列の契約期間開始・終了日を確認する。
8. 出力を閉じる。試験専用ツールは保存せずに閉じる。

【入力値】
N4＝準備値の年。P4＝準備値の月（1～12）。
```

### 期待結果
```
【画面確認】
・「支払いデータ抽出完了」が表示される。「支払いデータ無し」ではない。

【ファイル確認】
・実行ブックと同じフォルダーに、「【BCP対策】支払一覧_{年}年{月}月_{作成日時}.xlsx」が新しく生成される。
・「取込リスト」の対象契約IDは1行。複数機器を残した場合も契約単位で重複しない。
・その行のB＝サポートID、C＝納入先名、D＝担当店舗、E＝取引先コード、F＝取引先名、G＝契約No、I＝合計価格、J＝12が準備値と一致する。
```

## TL06-006

### 項番
TL06-006

### テスト項目
TL06（メーカ契約機器リスト作成）：現行版と改修版を同じ元データで実行し、取得件数と選んだ機器の情報・製番を比較すること。

### 前提条件
```
実施区分＝要確認。現行版と同じ元データを用意できた場合に実施する。

【この試験で確認すること】
同じ時点・対象条件の元データで現行版と改修版を実行し、全件数と選んだ既存機器の情報・製番を比較する。

【実施する人】
・実施者（試験を行う人）。
・準備担当者（両版のデータ時点・対象条件を確認し、比較対象の既存機器を選ぶ人）。

【実施者に必要なもの】
・実行可能な現行版のメーカ契約機器リスト作成、改修版の08フォルダー一式。それぞれ別の試験用フォルダーに置く。
・両版の接続先・認証とマクロ実行が準備されていること。本番のデータ更新は行わない。
・準備担当者が、両版のデータ移行時点・取得対象条件が一致すると確認していること。
現行DBと検証DBの更新時点が違う、現行版を実行できない等の場合は「実施不可」と理由を記録する。差を不具合とも一致とも断定しない。

【準備担当者が用意するデータ】
試験データ表：
| 項目 | 準備値 |
| 現行版・改修版のファイル名、接続先識別名（パスワード等は不要） | |
| データ時点・取得対象条件が一致する確認根拠 | |
| 比較する既存機器管理ID（1～3件）、取得区分 | |
| 同一IDの複数行が元データにある機器（存在する場合） | |

少なくとも1件は製番を持つ機器を選ぶ。両版の担当店舗・機器分類の再適用は行わず、取得直後の状態で比較する。

【開始時の状態】
Excelを起動していなくてよい。現行版と改修版は別々の試験用フォルダーに置く。
```

### 操作内容
```
1. 現行版を開き、「操作シート」の「データリスト作成」を押す。完了通知を控えて「OK」を押す。
2. 現行版の「取込データ」のデータ行数と、試験データ表の各IDの一致件数を控える。B列を完全一致で検索し、D・E・G・J・R・T～W・AR～AUの値を比較用ブックの「現行」シートへ項目名とともに値で転記する。
3. 現行版を保存せずに閉じる。
4. 改修版を開き、「操作シート」の②「データリスト作成」を押す。完了通知を控えて「OK」を押す。
5. 改修版について手順2と同じ件数と列を、比較用ブックの「改修」シートへ値で転記する。列名・機器管理IDで対応を合わせる。
6. 比較用ブックで両版の全データ行数、選んだIDの一致件数、転記した各値を対比する。日付は同じ年月日、金額・数量は数値、識別値は先頭0を含む文字として比較する。差があればID・項目名・両方の値を記録する。
7. 比較用ブックをエビデンスとして保存する。改修版は保存せずに閉じる。

【入力値】
両版とも全件取得。検索条件の入力はない。
```

### 期待結果
```
【画面・比較用ブック確認】
・両版の全データ行数が一致する。
・選んだ機器管理IDは両版で1行ずつ存在し、比較したD・E・G・J・R・T～W・AR～AUが一致する。
・取得元に重複がある機器を用意した場合も、改修版では1行にまとまり、保持される値が現行版と一致する。
・差がある場合はデータ時点の差・既存合意済み差異・処理の差を切り分ける。理由が確定するまで当該比較を合格としない。

【DB確認】
試験による更新確認は不要。比較前提である両DBのデータ時点・対象条件の確認は準備担当者が行う。
```
