# TL07（点検リスト作成） 用語表・根拠

2026-11-02。131の09「点検リスト作成ver1.53.xlsm」を基準とする。会社で編集した版とは未照合。業務マクロ・DB接続・帳票生成は実行していない。

## 対象と参照資料

- 実行用ExcelとMcm移行部品／McmMacroSettings.iniを含む09フォルダーを一式使用する。
- システムコード変換表.xlsxはINIのReference_01で参照する。未設定時の旧共有先へ勝手に切り替えない。試験ではコピーを使い、本番共有表を編集しない。
- 出力に外部の点検原紙は使わず、ブック内の「取込用点検データ」を複写する。TL08（点検依頼書作成）の追加原紙とは別。
- 根拠は[TL07調査記録](../../../../検証記録/20261102_業務利用ツール引継ぎ/TL07_調査)のVBA25モジュール、内蔵SQL、native_ui.json、source.json。VBAの接続認証文字列は調査用コピーで伏せている。

## 抽出・加工と表示列

通常取得はMcmNewDbのT21／点検データ抽出SQL。B18の空・指定でSQL2本を切り替え、12か月をパラメーター化する。選択月は年ではなく契約点検月の月部分で比較する。両契約が契約状態、実行日の有効期間、点検回数、機器分類等の条件もある。過去の契約があるだけでは取得できない。

I2選択時は前月末、解除時は当月末を基準に、契約点検月を1年ずつ進め、基準日より後にする。解約日が空でなければ、解約日より前の点検予定だけを残す（同日も除外）。PCとDBサーバーの現在日付に依存するため、実施日と両者の日付を控える。

取得後はサポートID付替表、機器修正リスト、機器構成名リスト、契約No空欄の「確認中」、点検コメントを適用する。警告が追加される場合がある。DBの値を無加工で全列転記する期待値にしない。

| 確認先 | 主な列 |
|---|---|
| 通常取得直後の取込データ | A＝機器管理ID、B＝ユーザ契約ID、C＝解約日、G＝点検予定年月、H＝契約点検月、I＝点検年度（期）、J＝サポートID、K＝納入先コード、L＝契約No. |
| 通常取得直後のM列追加後 | M＝照合キー（見出しは空欄）、N＝ユーザー名、O＝工場名、P＝システム名、Y＝機器構成名、AA＝品名、AB＝型式、AC＝数量、AE＝保守会社、AG＝取引先名 |
| 解約データ | A＝機器管理ID、C＝ユーザ契約解約日、D＝取引先契約解約日、G＝点検基準月、H＝契約点検月、J＝サポートID、L＝契約No.、M＝ユーザー名、X＝機器構成名、Z＝品名、AA＝型式、AB＝数量 |

解約取得はT21／解約データ抽出SQL。B24が日付であることを確認後、B18:C18をクリアし全月を選択して通常取得を実行する。その通常取得が0件なら、解約抽出へ進む前に中止される。解約SQLには取引先承認済み、点検回数等の条件もある。通常取得に存在する機器を除外し、確認キーで重複を除く。解約データにM列追加は行わない。

## 出力と未確定の操作順

②は実行Excelと同じフォルダーへ `Notes取込用点検データ_yyyymmdd_hhmm抽出.xls` を保存する。外部のNotesシステムへの登録はしない。

数量集約キーはユーザ契約ID、点検予定年月、契約点検月、サポートID、契約No、システム名、機器構成名、品名、型式。集約後、契約点検月（点検データH列）・サポートID・ユーザ契約ID・システム名・保守会社でグループ化し、1行10品目を上限にする。11品目等で複数行になるグループは「複数行点検データ」シートへ分ける。件数は元の機器行数と同じとは限らない。

**操作順は要確認。** ①末尾のCrate_ChkDataはM列を追加するが、②のDataCopyは34列の固定位置を想定する。date_edit（比較データ編集）にはM列削除がある。①から直接②へ進めるとユーザー名以降がずれる可能性がある。会社版と実運用で比較処理を挟むかを確認する。試験手順を成立させるために手動で列を削除しない。

この4処理は受領原本にもあり、VBA識別子の大小文字・空白を除いた比較を記録する。移行によって新しく発生した不具合とは断定しない。Notes照合の経路は結合候補とし、CSV形式と利用有無の確認後に手順を作る。

**解約取得も要確認。** Exclusion_ContListとEdit_Duplicationには、フィルター後に非表示行も含む全行範囲を削除する処理がある。同じ範囲操作をダミーデータで確認したところ、残すべき行も削除された。両処理は原本にも存在する。005は会社版の確認・修正まで保留し、解約データ0件を正常成功に読み替えない。根拠は[整合レビュー](../../整合レビュー_20261102.md)。

## メッセージ

すべてメッセージIDは「－」。文言中の改行は実装に合わせる。

| 条件 | 文言 |
|---|---|
| 月未選択 | 抽出対象月が選択されていません。／空行／処理を中止します。 |
| 通常0件 | 点検対象データがありません。／空行／処理を終了します。 |
| 通常完了 | データ抽出が完了しました。 |
| 型式警告の追記 | 品名／型式修正が必要です。／『機器修正リスト』シートを確認してください。 |
| 構成ID警告の追記 | 新規機器構成IDが追加されてます。／『機器構成名リスト』シートを確認してください。 |
| B24未指定・日付以外 | 解約日が指定されていません。／空行／処理を中止します。 |
| 解約0件・除外後0件 | 解約機器データはありません。 |
| 解約完了 | 解約データ抽出完了 |
| 再適用完了 | データ修正が完了しました。（対象に応じ警告を追記） |
| 出力完了 | 取込用データ作成完了 |
| 複数行の出力完了 | 取込用データ作成完了／空行／複数行データが生成されてます。 |

警告の追記は完了文との間に空行がある。本文では通知全文と対応するリストの追加行を記録し、未修正の行を出力完了済みと扱わない。
