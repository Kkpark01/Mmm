## 空欄になる可能性の追加確認

131版の検索SQL全文をローカルSQL Server上の架空の一時表で実行したところ、元データのサポートIDをNULLにした行は、IDがNULLのまま検索結果に含まれました。したがって、SQLの検索条件だけではサポートID空欄の結果を除外していません。前述の消去漏れは、こうした行が末尾にある場合に起こり得ます。

ただし、検証DBの実際の列定義、該当データの存在、会社編集版のSQLは未確認です。実環境で発生すると断定はできません。

## 受領済みDB定義との照合

受領済みのSQL Server向けテーブル定義では、MCM_UM_KIHON_MITSUMORI の SUPPORT_ID は NULL を許可する定義でした（[定義資料](../../../参照用/引継資料_20260915/参考資料/MCM_CreateTables_SQLServer.sql) の 1047 行目）。これは過去の参考資料で、稼働中の検証DBの現在の定義や該当データの存在を確認したものではありません。
