# TL02-005 支払一覧作成の模擬テスト

**手元の131版では仕様書と1点異なり、要確認です。** 14項目のうち13項目は一致し、実行中のブック名に関する1項目が異なりました。

| 確認内容 | 結果 |
|---|---|
| 「2026年10月度支払い一覧.xlsm」の生成 | 生成された |
| 必要な8シート | すべて存在 |
| 支払一覧の明細 | 3行 |
| I1の合計 | 116,670円で一致 |
| 通知文 | 「新規取引先があります。」を記録。仕様書の許容文言 |
| 実行中ブック名 | 試験用ブック名のまま。仕様書が期待する一覧名には変わらなかった |

原因は保存方式の違いです。受領した元版のCreateFileはThisWorkbook.SaveAs、手元の131版はSaveCopyReport（SaveCopyAs）を使います。**会社で変更した最新版は手元にないため、その版がどう動くかは未確認です。** 131版の差異を、会社版の不具合と断定していません。

この模擬ファイルは実原紙から作った試験用のコピーで、原紙由来の参照情報と試験用マクロを含みます。業務用には使用しないでください。元の配布ブック・原紙は変更していません。元ファイルの更新日時は今回測定していません。
