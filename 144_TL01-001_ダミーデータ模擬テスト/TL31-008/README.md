# TL31-008 入力欄の制御

**模擬合格：入力欄の主要な制御を実画面で確認しました。**

133版の試験用コピーと、この試験だけに作成したローカルの架空DBを使用しました。

- 付け替え元・先のサポートID欄に8文字を入力し、いずれも先頭7文字だけ表示されることを確認。
- 架空のサポートIDを入力し、対応する付け替え元・先の納入先名が表示されることを確認。
- 付け替え元・先の納入先欄およびメッセージ欄に文字を入力しても、表示内容が変わらないことを確認。
- 試験後、架空データが変化していないことを確認し、この試験用DBを削除。
