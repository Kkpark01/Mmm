## 反映内容・使用方法

本フォルダのExcelを、INT02-14更新済みの統合版として使用する。101や原本へ上書きする必要はない。

- INT02_審査承認シートのINT02-14、C23～G23・P23の6セルを置き換えた。
- 同じ期間に承認済み資料と審査中資料を混在させる条件を外し、今回の申請の差戻し後に前の期間の承認済みPDFが変わらないことを確認する内容とした。
- 前提、操作・入力値、画面／DB確認、確認・完了メッセージ、備考をINT02の構成に統一した。
- 項番、正常系の分類、未実施の状態、実績欄、件数集計を維持。対象外への変更は行っていない。
