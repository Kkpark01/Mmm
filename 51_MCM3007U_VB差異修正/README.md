# 51：MCM3007U VB差異修正

2026-09-30受領srcを基準に、VBのScreen・Designer・表示値定義と比較し、明確な差異を修正。元src全518ファイル・配備先は未変更。

## 修正内容

|項目|対応・根拠|
|---|---|
|見積レベル|1/2を「見積／概算」へ。VBのMcmMitsumoriLevelDataTable_Item.xmlに一致|
|パック契約|「なし／あり」を「通常／パック」へ。VBのMcmPackFlgDataTable_Item.xmlに一致。未設定は空表示|

|現在行|単一セルクリック時も該当行に▶を表示|
|共通仕様|layout/defaultと共通CSS/JSを使用。関連情報参照は別タブ、契約作成ウィザードは同一タブ|
