# 保守状況報告データ抽出の使い方

1. このフォルダを、ファイル一式で会社PCへコピーする。
2. 「保守状況報告データ抽出.exe.config」をメモ帳で開く。
3. Server・Database・Authentication・TrustServerCertificateを会社の検証DBに合わせて設定する。接続先の候補は `ILCM-SYSDEV,1433`、DB名の候補は `SYSDEV`。認証・証明書は会社で確認する。
4. SQL認証なら、Windowsの環境変数MCM_TOOL_DB_USER・MCM_TOOL_DB_PASSWORDを設定してからツールを開く。Windows認証なら、この2項目は不要。
5. 「保守状況報告データ抽出.exe」を開き、「開始」→「はい」を押す。
6. 「処理を終了しました。」が出たら、同じフォルダの「MM月保守状況.xls」を開く。同名ファイルがある場合は上書き確認が出る。

当日の有効な契約を集計するツールです。過去月の指定はできません。原紙のXLSは実行ファイルと同じフォルダに置いてください。原紙がない、店舗が対応しない、DBや保存に失敗した場合は、エラーを表示して止まります。理由は画面とLog.csvで確認できます。

初期設定では接続先が空欄です。会社PCにはMicrosoft Excelと.NET Framework 4系が必要です。

検証DBの実データでの照合は未実施です。詳細は [README](../README.md) を参照してください。
