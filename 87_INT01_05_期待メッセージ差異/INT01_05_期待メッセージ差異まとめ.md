# INT01～05 期待メッセージの差異まとめ

2026-10-15。対象は修正版80～84のINT01～05、合計124項番（32／29／19／25／19）。このMDは差異報告であり、元の仕様書全文・Excel・アプリsrcは変更しない。実機未実施。

VB定義を正とし、次を区別する。

- **仕様書の記載差**：現在の期待欄にWeb文言や省略が残る。
- **Web実装差**：仕様書をVBへ訂正しても受領srcの表示文言は異なる。
- **追加通知／表示順序**：同じ文章でも順序が違う、又はWebだけに通知がある。
- **未確定**：同時操作・例外経路等のVB全文をまだ確定できない。

現在の仕様書がWeb表示を明示している記載もあり、すべてを仕様書の誤記と断定しない。以下に訂正候補と実装差をまとめる。

**VBの期待・条件**

**受領Web又は現在の仕様書に記載された表示**

## 一致している文言と補足

- 新規個体期限の確認MSG_0102G、登録確認MSG_0007G、重複機器MSG_0038E、未選定MSG_0023E、点検／支払回数MSG_0103E／0104E、見積破棄拒否MSG_0025E、契約破棄確認MSG_0066Gの掲載文言はVB定義に照合できる。表示順・条件の一致まで一括保証するものではない。
- INT02共通A／Rの確認・完了文章はVB定義と一致。INT04-17等の「MSG_0147相当」「MSG_0148相当」は全文を補い、正式IDをMSG_0147G／0148Gと記載すると追跡しやすい。
- INT04／05で「確認→完了」とだけ書く箇所は、対応する条件が成立する場合にVB全文を明示する。表示するエラーが確定していない「本文で指定した通知」は推測で埋めない。
- 参照・取消・工程対象外は「登録完了を期待しない」等を記載する。メール対象外INT02-16～22へ送信通知の新規期待を追加しない。
- 登録成功・申請成功と、文字列の一致は別判定。文言差があっても保存済みデータを同じ条件で再登録しない。

## 確認範囲と残る限界

全124項番の期待メッセージ欄と共通M／S／A／Rを読取確認した。差が見つかった文章はVB定義と関連コードを照合した。VB定義があることだけで、各異常経路で必ずそのIDが出るとは断定しない。

D12・D13と「本文で指定した通知」の一部はVB共通例外・実機経路の追加確認が必要。ブラウザー固有の離脱確認・配備DB障害・実機のタイトルやアイコン・独立した人のレビューは未確認。未確定事項を「差なし」へ変更していない。

対象全件の対応と元の期待欄は[全124項番の確認一覧](INT01_05_期待メッセージ_全項番確認.md)、入力資料・根拠のハッシュは[検証記録](検証結果.json)。一覧の「確定差なし」は抽出した期待欄で今回の確定差を割り当てていない意味であり、全機能・全メッセージの実機合格ではない。
