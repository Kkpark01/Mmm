# MCM3007U 契約・解約：機能と一覧表示

2026/09/18受領のsrcを基にした差替え用6ファイルです。元のmcm-web/srcは変更していません。
このフォルダのsrc内を、同じ相対パスに上書きしてビルド・再起動してください。27とファイル重複はありません。

## 機能の修正

- 取引先の契約時間を文字順ではなく数値順に変更（2→8→24）。VBのUVATableAdapter.xmlのTO_NUMBERに対応します。
- 契約破棄後、取引先契約が破棄・元見積が見積となった行を、古いビューの判定にかかわらず「見積」で検索できるように変更。契約作成／破棄リンクも見積状態に合わせます。MCM1003Uの既存修正と同じ判定です。
- VBと同様に、不正情報がある取引先契約番号の末尾にその情報を付記。
- 納入先一覧が0件なら下段検索を中止し、3段ともクリア。
- ブランド構成がないプラントから機器構成画面への遷移を中止。
- 契約破棄の支払確認から更新までSERIALIZABLEトランザクションで保護。

## 表示・操作の修正

VBの3段構成と列順を維持し、MCM1003U・2004Uの表表示を参照しました。

- 白背景、薄いグレーの見出し、24px行高、行頭固定。
- 行頭クリックは行全体をグレー、データセルクリックは該当セルをグレーにします。どちらも下段一覧を連動させます。
- 絞り込み後の行番号を1から表示。
- 下段取引先の選択行と各一覧のスクロール位置も同じ検索世代内で復元。
- 更新権限がなければ契約操作列自体を非表示（VB準拠）。
- 契約破棄の確認文言を「契約を破棄します。よろしいですか？」へ統一。
- 列幅は維持し、狭い画面では各一覧の横スクロールを使用。
