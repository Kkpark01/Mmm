# 配備後の確認手順

## 事前準備

検証DB・検証用担当者を使用し、取引先契約の作成権限あり／参照のみの利用者を準備。登録前の契約・期間IDと値を控える。直接POSTの確認ではCSRFを維持する。保存先・接続先を確認してから操作する。

## #517

1. 編集可能な1005Uの期間で契約時間帯を24にし、他に変更がある状態で登録。完了後に開き直し24を確認する。DBの同じTK_KIKAN_IDの値も読取り照合する。
2. 25を入力し別項目へ移動。範囲エラーを1回表示し、既存の入力復元が働くことを確認。
3. 25を入力して登録。保存・成功通知・画面遷移をしないことを確認。
4. 開発者ツール等でクライアント検査を迂回して25をPOST。サーバーの範囲エラーとDB不変を確認。
5. 新規・機器選定後の未登録状態、申請・発行でも不正値を拒否し、部分登録しないことを確認。
6. 空欄・0・23・24、負数・非数値・桁超過、日付・点検回数・支払い回数、参照専用期間を確認。

## #523

1. 1006U1で有効な期間を入れ、同じ機器明細ID＋個体管理IDが重複する選択見積をチェック。
2. 「次へ」を押し、MSG_0038Eが1回表示され、1画面目に留まることを確認。期間・見積チェックが保持されることを確認。
3. 重複かつ出精値引きの条件でも重複を先に通知し、2画面目へ行かないことを確認。
4. 重複のない見積で従来どおり2画面目に進むこと、未選択・期間不正の既存通知、参照権限を確認。

## #529

1. 未選定データを含む1006U2を表示。機器構成一覧の見積依頼NO空欄行を選ぶ。
2. 契約有無チェックをクリック。MSG_0081Eが1回表示され、OFFのままであることを確認。
3. 対応する納入機器明細・機器個体の空欄行でも同じ確認を行う。Spaceキーも確認。
4. 選定済みの行は従来どおりON/OFF・親子伝播できることを確認。連続クリック中の二重通知なし、参照権限の非活性も確認。
5. 摘要後の1005Uで未選定機器が追加されないことを確認。直接POSTで不正ONを送っても取り込まれないことを確認。

DB書換えや既存実務データの削除で重複データを作らず、担当者が準備した検証用データを使う。
