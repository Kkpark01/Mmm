# 38 MCM1005U：既存契約の保存・期間表示の修正

基準：2026-09-25受領src。元の `mcm-web/src` は変更していません。

**既存契約の表示・登録で見つかった不具合の修正版です。MCM1005U全機能のVB移植完了版ではありません。** 未実装・仕様差は下記に残しています。

## 修正内容

| 問題 | 修正 |
|---|---|
| 登録時に未編集の状態・承認状態・金額・取引先情報を初期値/nullで上書き | DBの現在値を基に編集対象項目だけを更新。依頼事業所など表示専用項目も保持 |
| タブ移動で未保存入力が消える／選択タブだけ送信 | 全期間を同一フォームに保持し、ブラウザ内で切替。選択タブ番号も保持 |
| 点検月・可能曜日・夜間対応が送信されても保存されない | 点検行と月チェックを保存。保守会社など未編集項目は保持 |
| 支払明細を全削除して2000年の年月で再作成 | 契約期間の実年月で作成。既存IDを保持し、チェック解除はOFFフラグ・取消日時を記録 |
| 入力日付の誤りがnullとして扱われる | 実在日付を厳密に判定。スラッシュ・ハイフン入力に対応 |
| 登録エラーで再読込すると入力が消える | 入力チェック、数値バインド失敗、DB例外で元フォームを復元。SQL詳細は画面に表示しない |
| 先行更新を後から上書きできる | 表示時の契約・期間・点検・支払の更新日時を照合。更新対象をトランザクション内でロック |
| 次回更新日が選択した古い期間の翌日になる | 最終期間タブの終了日翌日から設定 |
| 機器情報のtbodyに表示処理がない | VBのMCM_TK_KIKIJOHO SQLをSQL Server用に変換して表示 |
| 点検月のテンプレートが存在しないメソッドを呼ぶ | `getTsukiAt`へ修正 |
| 申請の添付条件、承認中の編集制限がない | 添付なし・承認済添付の再申請をチェック。審査中等はヘッダー備考・更新内容のみ更新 |
| 他契約／承認処理中の添付を削除できる | 契約への所属、削除可能な承認状態をサーバーで確認 |
| 添付追加・ダウンロードが未実装 | 選択期間への追加、同名拒否、権限・所属確認付きダウンロードを実装。追加失敗・ロールバック時は新しいファイルだけ削除 |
| 編集中に申請すると先に登録する必要がある | 登録・申請の確認後、入力を保存して申請。同一トランザクションで処理し、失敗時はフォームを復元 |
| 契約発行の画面連携とテンプレートがない | 提供されたMCM1003Pのxlsを使用。編集時は保存後に出力、未編集時は保存せず出力。新規・更新・解約と前の有効期間の比較を実装 |
| 帳票がxlsx前提、VBとセル位置が不一致、3ページ目に前ページの行が残る | xls読込・出力、セル位置をVBと照合、白紙の継続シートを先に複製。担当者印も名前付き図形に設定 |
| 戻りURLの取引先名に `&` / `+` があると破損 | URL変数をエンコード |
| 1003から来ても「閉じる」がメニュー固定 | 遷移元をセッションに保持して1003へ戻る。1009の旧セッション連携も受取 |

短い契約期間の月生成はVBの「1年未満なら開始日から1年まで補完」に合わせています。VB `GetTsuki` 内の `AddYears(11)` は機械的にコピーせず、期間内の各年月を列挙します。また取消月の再チェックは既存明細を再有効化します。

## 残件・VBとの差（重要）

1. **新規契約／MCM1006U選定結果の完全な移植**：受領実装は選定結果で既存機器を全置換する方式。VBの期間追加・機器履歴・点検継承・契約期限更新まで一致するとは確認できていません。この経路を含めた業務完了判定は不可。今回の保存検証は登録済み契約です。不完全な新規フォームを契約ヘッダーだけで登録することは許可していません。
2. **管理者ロック解除**：未対応。MCM1003Pはテンプレート受領により出力連携まで対応しました。会社環境で実データ・印刷結果を確認してください。
3. **未保存入力での機器変更・添付削除**：入力破棄を避けるため、登録を先に行う案内を表示します。申請時の保存は今回対応済みです。
4. **全列のVB表示再現**：点検の品名・型式等の詳細な親子機器対応、コード値の全表示名変換、全遷移元の参照専用モードは継続確認が必要です。
5. **共通仕様の全面適合**：受領srcには指定されたDateUtils・TantoNameResolverが存在しないため、既存監査表示を残しています。全メッセージのproperties統一、選択専用表の▶列、全セルのフォーカスアウト検証等も残っています。共通仕様全項目への適合済みとはしていません。

会社環境では、登録済みの複数期間を持つ契約で、登録前後の契約状態・取引先ID・金額が保持されること、点検／支払明細の年月・OFFフラグ、A/B同時更新の拒否を先に確認してください。
