## 動作

- メニューへ戻ると、0010Uの検索条件・検索結果・比較情報などの一時保存を解放する。
- メニューから納入先検索を開き直すと、未検索の空画面を表示し、前回条件での自動再検索を行わない。
- 納入先マスタなどの詳細画面から「戻る」場合は、検索条件を保持して最新情報を読み込む。
- 登録済みの納入先・プラントデータは削除しない。
