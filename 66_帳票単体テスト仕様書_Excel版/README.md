## Excelの構成

「機能ID・帳票名一覧」「仕様書課題一覧」「単体テスト目次」「共通確認」、10帳票の個別シート、「統合対応」の計15シート。

帳票別シートは既存テンプレートに合わせ、画面情報・根拠ソース・機能一覧・単体テストケースの順です。ケース表は、項番、分類、テスト項目、前提条件、操作内容、期待結果、期待メッセージ、テスト結果、実施者、実施日、不具合内容、再テスト結果、再テスト実施者、再テスト実施日、最終判定、備考／根拠の16列。長文の折返し・行高・列幅を調整しました。

帳票別284ケース。共通6観点は同じ実施結果を再利用し、284件に二重加算しません。旧4項番は「統合対応」で追跡できます。仕様未確定Q01〜Q06と実装不具合F01〜F04を課題一覧に転記しています。

## 記入方法

H列のテスト結果とL列の再テスト結果は「未実施、OK、NG、保留、対象外」から選択。O列の最終判定は再テスト結果を優先し、両方空欄なら「未実施」です。実施者・日付・不具合内容は必要に応じて入力してください。

目次は帳票別ケース数・OK・NG・保留・未実施・実施率を集計します。実施率は（OK＋NG）÷登録ケース数で、対象外を含む母数です。実績欄は空欄、最終判定284件は未実施、実施率0%で保存しています。数式のある集計欄・最終判定欄は上書きしないでください。
