# TL04（見積作成） 単体テスト仕様書

準備方針：[共通方針と準備記録](../00_試験準備の共通方針.md)。このケースで使う既存入力値・期待件数・対象版を準備担当者が記入する。DBの試験データ新規登録は行わない。

対象：見積作成ver9.02.xlsm（改修版）。シート「操作シート」にサポートID、見積No、撤去日スライサーを入れて「(*ﾟДﾟ)σ凸」を押すと、新MCM（SQL Server）からプラントの機器と終息日（見積Noがあれば店舗見積も）を取り出し、操作シートと、ツールが作るシート（終息日一覧、明細①〜③テンプレートなど）に書く。DBは読むだけで、更新しない。

凡例：
- 実施者：試験を行う人。Excelでツールを実行し、操作シートと、ツールが作るシートを確認する。
- 準備担当者：検証DBにあるプラント・店舗見積から試験用のデータを選び、試験データ表に値を書いて実施者に渡す人（新しく登録はしない）。
- 試験データ表：準備担当者が、選んだデータの値を書く表。各ケースの前提条件にある。
- 特記事項テンプレート：操作シートA11 に書かれた場所のファイル（今は共有フォルダー）。本番は共有フォルダーを読む。共有フォルダーに入れないPCで試験するときは、A11 を一時的に写しの場所に書き換え、ツールは保存せずに閉じる（TL04\用語表.md 1章）。
- 各ケースの「前提条件」「操作内容」「期待結果」は、そのケースだけを読んで実施できるように書いてある。他のケースは参照しない。
- 準備担当者が既存データを選定する。準備未完のケースは開始せず、未確認を合格へ読み替えない。
- このツールにはメッセージIDがないため、期待メッセージの「メッセージID」は「－」とする。
- 実施区分：通常／要確認／開発者テスト／実施不可／除外候補（test-spec-common-rules.md 14.7章）

項番の欠番：

| 項番 | 理由 |
|---|---|
| 004 | 「見積データ」による見積書の作成。DBを使わず、元のツールと同じ処理のため作らない（作成者回答 2026/11/02） |
| 005 | 接続エラー。共通部品が TL11（店舗見積実績検索）と同じため、TL11-007 で確認する |

## TL04-001

### 項番
TL04-001

### テスト項目
TL04(見積作成)：サポートIDだけを入れて「(*ﾟДﾟ)σ凸」を押すと、そのプラントの撤去されていない機器が取り出され、操作シートに納入先・工場名・システム名・納入プロダクトが表示され、保守仕様明細の枠のシートができること

### 前提条件
```
【この試験で確認すること】
撤去日スライサーと見積Noを空欄にして「(*ﾟДﾟ)σ凸」を押すと、サポートIDのプラントの機器が新MCMから取り出されること。撤去日が登録された個体は出ないこと。操作シートに納入先・工場名・システム名・納入プロダクトが表示され、機器の種類ごとに保守仕様明細のシートができること。

【実施する人】
・実施者（試験を行う人）
・準備担当者（検証DBから試験用のプラントを選び、試験データ表を渡す人）

【実施者に必要なもの】
・Excel（マクロを有効にできること）が入ったPC。
・改修版のフォルダー「03_見積作成」一式を、PCにコピーしてあること。中の「Mcm移行部品」フォルダーも、同じ位置関係のままコピーする。
・OLE DB ドライバー（MSOLEDBSQL19）が、PCに入っていること。
・SQL認証の場合のみ、MCM_MACRO_DB_USER・MCM_MACRO_DB_PASSWORDを実施者の環境に設定する。Windows認証では不要。認証情報は本書へ書かない。
・接続先が本番ではないこと（依頼元に確認済みであること）。
・特記事項テンプレート：PCから共有フォルダー（操作シートA11の場所）に入れること。入れない場合は、準備担当者から「特記事項テンプレート.xlsx」の写しを受け取り、PCの任意のフォルダーに置く。

【準備担当者が用意するデータ】
検証DBにあるプラントから、次の1つを選ぶ（新しく登録しない。以下、プラントP）。
・撤去されていないブランドが1つ以上あり、そのブランドに、撤去日のない個体（以下、個体Z）と、撤去日のある個体が2つ以上ある。撤去日のある個体のうち、撤去日の新しいものを個体X、古いものを個体Yとする（XとYの撤去日は違う日にする）。
・個体X、Y、Zは、個体名で区別できる。
選んだら、下の「試験データ表」を書いて実施者に渡す。値は、新MCMの画面かDBで確かめた値を書く。共有フォルダーに入れない実施者には、業務利用ツール\参照先\保守見積業務用マスタ\特記事項テンプレート.xlsx の写しも渡す。

試験データ表（準備担当者が記入する）：
| 項目 | 値 |
| サポートID（7桁） | |
| 納入先名、工場名、システム名（プラント名） | |
| 撤去されていないブランドの名前（表示順に） | |
| 機器の種類（情報系／BoxCell／制御系のうち、あるもの） | |
| 個体Zの個体名、品名 | |
| 個体Xの個体名、品名、撤去日 | |
| 個体Yの個体名、品名、撤去日 | |

【開始時の状態】
Excelを起動していなくてよい。
```

### 操作内容
```
1. エクスプローラーで、コピーしたフォルダー「03_見積作成」を開く。「Mcm移行部品」フォルダーの McmMacroSettings.ini をメモ帳で開き、サーバー名・DB名が準備記録の検証接続先と一致することを確認する。変更せずにメモ帳を閉じる。

2. 「見積作成ver9.02.xlsm」をダブルクリックで開く。画面上部に、マクロを有効にするかを尋ねる黄色の帯が出た場合は、帯のボタンを押下して有効にする。

3. シート「操作シート」を選ぶ。シートの見出しに「終息日一覧」「明細①テンプレート」「明細②テンプレート」「明細③テンプレート」がないことを確認する。ある場合は、試験を中止して記録する。

4. 共有フォルダーに入れない場合だけ、A11（特記事項テンプレートファイル指定）を選び、受け取った「特記事項テンプレート.xlsx」の場所（フォルダー名＋「\特記事項テンプレート.xlsx」）を入力して、Enterキーを押す。

5. B2（サポートID）に試験データ表のサポートIDを入力する。B3（8h見積No）、B4（24h見積No）、B6（撤去日スライサー）を選び、Deleteキーで空にする。（保存されたブックでは、B2に「1700140」、B3に「11SCE571」、B4に「11SCE581」が入っている。）「ソフトウェア保守のみ」のチェックボックスがONなら外す。

6. 「(*ﾟДﾟ)σ凸」ボタンを押下する。メッセージが表示されたら、内容を確認して「OK」を押下する。

7. シート「操作シート」のG2〜G4、G7から下、H7から下、L3から下を確認する。

8. シート「終息日一覧」を選び、1行目の見出しと、N列（個体名）、P列（品名）、U列（撤去日）を確認する。

9. シートの見出しで、「明細①テンプレート」「明細②テンプレート」「明細③テンプレート」のどれがあるかを確認する。

10. Excelを閉じる。保存するかを尋ねられた場合は、保存しない方のボタンを押下する（ツールのブックを変えないため。手順4で書き換えたA11も元に戻る）。

【入力値】
・サポートID（B2）＝試験データ表のサポートID
・8h見積No（B3）、24h見積No（B4）、撤去日スライサー（B6）＝空欄
・ソフトウェア保守のみ＝OFF
・特記事項テンプレートファイル指定（A11）＝共有フォルダーに入れる場合は変更しない。入れない場合は、受け取った写しの場所
```

### 項番
TL04-003

### テスト項目
TL04(見積作成)：8hと24hの見積Noを入れて「(*ﾟДﾟ)σ凸」を押すと、2つの見積の明細が取り出され、操作シートに見積No・見積期間パターン・店舗見積IDが表示され、店舗見積IDごとのシートができること

### 前提条件
```
【この試験で確認すること】
サポートIDと、8h・24hの見積Noを入れて「(*ﾟДﾟ)σ凸」を押すと、2つの見積の明細が新MCMから取り出され、シート「店舗見積」に書かれること。操作シートに、作成日、見積作成者、見積No、見積期間パターン、期間ごとの店舗見積IDが表示されること。店舗見積IDごとに、その明細だけのシートができること。

【実施する人】
・実施者（試験を行う人）
・準備担当者（検証DBから試験用の見積を選び、試験データ表を渡す人）

【実施者に必要なもの】
・Excel（マクロを有効にできること）が入ったPC。
・改修版のフォルダー「03_見積作成」一式を、PCにコピーしてあること。中の「Mcm移行部品」フォルダーも、同じ位置関係のままコピーする。
・OLE DB ドライバー（MSOLEDBSQL19）が、PCに入っていること。
・SQL認証の場合のみ、MCM_MACRO_DB_USER・MCM_MACRO_DB_PASSWORDを実施者の環境に設定する。Windows認証では不要。認証情報は本書へ書かない。
・接続先が本番ではないこと（依頼元に確認済みであること）。
・特記事項テンプレート：PCから共有フォルダー（操作シートA11の場所）に入れること。入れない場合は、準備担当者から「特記事項テンプレート.xlsx」の写しを受け取り、PCの任意のフォルダーに置く。

【準備担当者が用意するデータ】
検証DBにある店舗見積から、同じサポートIDの見積を2つ選ぶ（新しく登録しない）。8hの見積を見積E、24hの見積を見積Fとする。
・見積Eと見積Fのサポートは同じで、そのプラントに撤去されていない個体が1つ以上ある。
・見積Noに「SW」「HW」を含まない。
・2つの見積の見積作成者が同じ。
・明細の品名に「寿命品予防交換」「ｻｰﾋﾞｽ期限延長」を含むものがない。
（保存されたブックの値（サポートID＝1700140、8h見積No＝11SCE571、24h見積No＝11SCE581）は、2026/11/02 に検証DBで店舗見積8行が取り出せることを確かめてある。上の条件に合えば使ってよい。）
選んだら、下の「試験データ表」を書いて実施者に渡す。値は、新MCMの画面かDBで確かめた値を書く。共有フォルダーに入れない実施者には、業務利用ツール\参照先\保守見積業務用マスタ\特記事項テンプレート.xlsx の写しも渡す。

試験データ表（準備担当者が記入する）：
| 項目 | 値 |
| サポートID（7桁） | |
| 見積EのNo（8h）、見積FのNo（24h） | |
| 見積作成者 | |
| 見積期間（開始日の早い順。同じ期間は1行）と、その期間の見積Eの店舗見積ID・見積Fの店舗見積ID | |

【開始時の状態】
Excelを起動していなくてよい。
```


## TL04-006

### 項番
TL04-006

### テスト項目
TL04(見積作成)：同じ時点のデータで、元のツールと改修版の取得結果（終息日一覧、店舗見積）が一致すること

### 前提条件
```
【この試験で確認すること】
旧DB（Oracle）と新MCM（SQL Server）が同じ時点のデータを持っているとき、元のツールと改修版で同じサポートID・見積Noを入れて「(*ﾟДﾟ)σ凸」を押すと、シート「終息日一覧」と「店舗見積」の行数と値が一致すること。

【実施する人】
・実施者（試験を行う人）

【実施者に必要なもの】
・改修版の試験（TL04-001など）が行えるPC。
・元のツールが動く環境（旧DBに接続できること。準備は依頼元に聞く）。
・元のツールのフォルダー一式を、PCにコピーしてあること（元のフォルダーでは実行しない。元のツールは、実行したフォルダーにファイルを作るため）。
・改修版のフォルダー「03_見積作成」一式を、PCにコピーしてあること。
・旧DBと新MCMのデータが、同じ時点のものであること（移行のリハーサルの直後など）。依頼元に確認済みであること。
・特記事項テンプレート：PCから共有フォルダー（操作シートA11の場所）に入れること。入れない場合は、準備担当者から「特記事項テンプレート.xlsx」の写しを受け取り、PCの任意のフォルダーに置く。

【準備担当者が用意するデータ】
準備担当者が両DBの同時点データから既存サポートID S、同プラントに対応する8h見積No E8、24h見積No E24を選ぶ。新規のプラント・見積・単価は登録しない。
終息日一覧と店舗見積に対象が取得できる結合先を確認し、両DBの対象集合と比較用の期待件数・代表値を控える。原紙・特記事項資料も揃える。
試験データ表：
| S／E8／E24（入力値そのもの） | |
| 同時点確認の日時・方法／各対象の識別子 | |
| 終息日一覧・店舗見積の期待件数／代表値 | |
| 両版の起動先・原紙・資料パス | |
両方の見積時間の既存対象がなければ、不足分を未確認と記録する。空の結果同士で合格にはしない。

【開始時の状態】
Excelを起動していなくてよい。
（2つのツールはファイル名が同じため、Excelで同時には開けない。1つずつ実行し、結果を別のブックに写して比べる。）
```

### 操作内容
```
1. Excelで新しいブックを作り、シートを6つにする。シート名を「元_終息」「改修_終息」「比較_終息」「元_見積」「改修_見積」「比較_見積」に変える。このブックを「TL04-006_比較.xlsx」の名前で、ツールのフォルダーとは別の場所に保存する。

2. 元のツールの「見積作成ver9.02.xlsm」を開き、マクロを有効にする。シート「操作シート」で、B2＝試験データ表のS、B3＝試験データ表のE8、B4＝試験データ表のE24 になっていることを確認し、B6 を Deleteキーで空にする。共有フォルダーに入れない場合は、A11 に、受け取った「特記事項テンプレート.xlsx」の場所を入力する。「(*ﾟДﾟ)σ凸」ボタンを押下し、表示されたメッセージはすべて「OK」を押下する。

3. シート「終息日一覧」のA1から最終行・AA列までを選んでコピーし、「TL04-006_比較.xlsx」のシート「元_終息」のA1に、値だけを貼り付ける（「貼り付け」の「値」）。同じように、シート「店舗見積」のA1から最終行・AA列までを、シート「元_見積」のA1に値だけを貼り付ける。元のツールを、保存しないで閉じる。

4. 改修版の「見積作成ver9.02.xlsm」を開き、手順2と同じ操作をする。

5. 手順3と同じ操作で、結果を「改修_終息」「改修_見積」のA1に、値だけを貼り付ける。改修版を、保存しないで閉じる。

6. 「元_終息」と「改修_終息」、「元_見積」と「改修_見積」の最終行の番号を見て、行数を比べる。

7. 4つのシートのそれぞれで、2行目から最終行までを、次の順で並べ替える（「データ」タブの「並べ替え」。すべて昇順）。
　・「元_終息」「改修_終息」：A列（機器管理ID）→ C列（機器明細ID）→ B列（個体管理ID）
　・「元_見積」「改修_見積」：C列（店舗見積ID）→ Q列（店舗見積機器明細ID）→ S列（機器管理ID）

8. シート「比較_終息」のA1に「=IF(元_終息!A1=改修_終息!A1,"","違う")」と入力し、A1をA〜AA列、最終行（手順6の行数）までコピーする。AC1に「=COUNTIF(A:AA,"違う")」と入力する。シート「比較_見積」も、参照するシート名を「元_見積」「改修_見積」に変えて、同じようにする。

9. 「TL04-006_比較.xlsx」を保存する。

【入力値】
・サポートID（B2）＝試験データ表のS、8h見積No（B3）＝試験データ表のE8、24h見積No（B4）＝試験データ表のE24（2つのツールとも）
・撤去日スライサー（B6）＝空欄（2つのツールとも）
```

### 備考
```
【実施区分】通常
【根拠】元のツールのSQL（非表示シート「終息日抽出」「見積情報抽出」）と、改修版の内蔵SQL queries/T34_00_1_01.sql、T34_01_00_01.sql は、たどるテーブルと抽出条件が同じ（撤去日の条件は 2026/11/02 に確認。見積Noの比べ方は、改修版を 2026/11/02 に元のツールに合わせて直した）。列の型は、どちらも同じ並び（arraytype）で書く。

```
