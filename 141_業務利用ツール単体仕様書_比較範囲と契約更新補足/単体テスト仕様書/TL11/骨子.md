# TL11（店舗見積実績検索） 骨子

新規に試験専用の品名・見積を登録しない。既存品名から検索語を選び、全期待行を12列で準備する。

| 項番 | 目的 | 準備 |
|---|---|---|
| 001 | 大小文字・見積状態・12列・順序 | Q小／Q大、全N行の期待表、除外候補・並び分岐の既存対象 |
| 003 | 半角と全角の区別・正常0件 | 既存Q半とその全角形Q全、Q全は独立した比較で0件と確認 |
| 005 | 未入力停止・旧結果消去 | 既存Qで正常取得して保存した試験コピー |
| 006 | 現行比較 | 同時点で両版に結果がある既存品名語Q |
| 007 | SQL認証環境変数なし | 正常取得済みコピー、既存Q、SqlLogin、退避・復元手順 |

002は見積時間の判断保留、004は003への統合で欠番を維持。結果を3件に限定せず、同じ検索語で一致する他の既存行も期待表へ含める。不足する状態・順序・先頭0の分岐は未確認として残す。

全角半角の期待は変更しない。対象の会社版への比較修正反映は未確認で、準備統一とは別に記録する。
