# マクロの出力先変更（検証用）

2026-10-30追記：15_TSSA保守情報更新は内蔵SQLにOracle関数の変換漏れが見つかったため、[136の修正版Excel](../136_TSSA保守情報更新_SQL変換漏れ修正/README.md)へ差し替えてください。接続設定はそのまま使用します。

## 使うもの

`配布用/MCM業務マクロ` に15本のマクロをまとめています。使用する業務のフォルダを、Excel・設定・テンプレートを含めてコピーしてください。`管理者用` のVBAは、手作業で既存Excelに修正を反映する場合にだけ必要です。

## 出力先

01・02・03・04・05・06・08の自動保存先を、実行用Excelと同じフォルダに変更しました。フォルダ名を変更しても利用できます。例：`02_支払いデータ取得` のExcelを実行すると、支払い一覧も同じ `02_支払いデータ取得` に作られます。

残りのマクロは保存処理を変更していません。元から保存先を選択する処理は、選択先に保存されます。ファイル名・同名時の既存の扱いは変更していません。出力ファイルと実行用Excelを取り違えないよう、続けて操作する場合は元の実行用Excelを開いてください。

元のソースでは01・02・03・04・06、および05・08の支払一覧は実行用Excelと同じフォルダへ保存していました。05・08の店舗別機器一覧は、元の処理では画面上に作成したブックを表示する形で、今回の修正版では従来の修正版にある自動保存を維持し、その保存先を変更しています。

## 元にした版と注意点

- 02は124、05は127、08は129の速度改善「検証版」を使用しています。それぞれの改善を含むため、122などを後から上書きすると消えます。15本ともこの131の配布用を基準にしてください。
- それ以外は122が元です。03・10の追加原紙も引き継いでいます。
- 124・127・129は実DBで元の結果との全件一致、Excelからの取得と帳票までの一連の動作が未確認です。業務利用の前に検証環境で同じ条件・同じDBの結果と照合してください。02のSQL単体は31秒・1,569件、05・08で利用するSQL案は1分49秒・253,182件との報告がありますが、マクロ全体の処理時間ではありません。
- 実行PCのDB認証設定、各種原紙や共有先の準備が必要です。詳細は配布用の「最初にお読みください」「未確認事項」と各業務フォルダの「使い方」を参照してください。10のTSSA参照先は未確認です。
- 既存の出力結果フォルダや過去のファイルは移動・削除していません。

## 管理者向け反映

Excelファイルをフォルダごと使用する場合、VBAの取り込みは不要です。既存のExcelへ手作業で反映する場合は、同じ番号の `管理者用/VBA取込用/McmOutput.bas` をインポートする前に、元の同名モジュールをバックアップして置き換えてください。02・05・08に速度改善も反映したい場合は、このモジュールだけでは不足します。131のExcelを丸ごと利用してください。

## 確認状況

7本のExcelをテスト用コピーで開き、任意のフォルダ名でも出力先が実行用Excelと同じになることを確認しました。02は仮のファイルを実際に保存することも確認しました。変更前後のExcel内部を比較し、保存先用VBA以外のVBA・シート・SQLなどが同一であることを確認しました。

実DB・実データを使った帳票出力、同名ファイルがある場合の実際の操作、全体の処理時間・結果一致は未確認です。利用環境で確認してください。
