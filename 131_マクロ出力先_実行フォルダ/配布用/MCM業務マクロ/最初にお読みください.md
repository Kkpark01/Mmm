# 最初にお読みください

1. 今回の配布は業務別15本です。業務フォルダの実行用xlsmから操作します。ファイル名・ボタン・入力欄は受領原本に合わせています。
2. 「Mcm移行部品/McmMacroSettings.ini」があるDB業務では、会社で確認した接続設定を使用します。初期値はILCM-SYSDEV,1433／SYSDEV、Backend=SQLSERVER、Provider=MSOLEDBSQL19、Authentication=SqlLoginです。SQL認証が利用できると確認できた設定ではなく、121の設定を引き継いだ初期値です。
3. SQL認証では、実行者の環境変数MCM_MACRO_DB_USER／MCM_MACRO_DB_PASSWORDを会社の管理方法で設定し、Excelを開き直します。Windows認証が利用できる場合はAuthentication=Windowsへ変更します。Web画面のログインとは別です。パスワードをExcelやINIへ記入しません。
4. Excelと同じ32／64bitに対応したMicrosoft OLE DB Driver 19 for SQL Serverが必要です。インストールやマクロ利用の許可は社内ルールに従います。
5. SQLはExcel内へ格納済みです。管理者用のSQLやVBAをコピーする必要はありません。旧Oracleへの切替はありません。
6. 共通取得モジュールMcmNewDbを持つ11本では、Alt+F8の「Mcm接続確認」で接続を確認できます。この操作は実際のDBへ接続するため、設定を確認してから利用者が実行します。終息リスト・メーカ契約機器リストの2本は、管理者のDB確認後に少量の取得から確認します。
7. 会社で存在を確認したキーを入力して少量取得し、件数・ID・日付・金額を確認します。元と同じ操作で帳票作成へ進めます。
8. 自動保存する帳票は、原則として実行用Excelと同じフォルダに保存します。元から保存先を選ぶ処理は選択先です。
9. 同梱原紙や、業務で参照するマスタ・変換表も必要です。共有先が変わった場合はINIのReference_*を設定します。設定例と対象は業務フォルダの説明にあります。元から入力セルや選択ダイアログで指定する参照先は、その操作で指定します。
10. 02の支払い一覧など、出力した確認用ファイルではなく、元の実行用Excelから操作してください。
